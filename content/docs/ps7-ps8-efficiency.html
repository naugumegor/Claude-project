Куда деваются ватты КПД, нагрузка, потери и передачи

Вся тема держится на одной мысли: энергия на входе = полезная + потери. Всё остальное (коэффициент нагрузки, оптимум, средний КПД, передачи) просто разные способы посчитать эти три куска. Ниже словарь всех обозначений, теория по-человечески, разбор всех семи задач и пробный тест в двух вариантах.

02

КПД и коэффициент нагрузки

Представь кофемашину: из розетки она берёт энергию (вход), часть превращается в горячий кофе (полезная), остальное греет кухню (потери). Ничего не исчезает:

Pin = Pu + Plossзакон сохранения энергии, только в мощностях

КПД, η

η = PuPin

Какая доля входа стала полезной. Отсюда же Pin = Pu/η и Ploss = Pu(1/η − 1).

Нагрузка, x

x = PuPn

Насколько машина загружена относительно паспорта. Значит, Pu = x·Pn: полезную мощность при любой нагрузке получаешь умножением.

Ловушка

Номинальная мощность Pn это полезная мощность при x = 1, не то, что машина берёт из сети. Мотор на 5 кВт при полной нагрузке выдаёт 5 кВт на вал, а из сети тянет 5/η, больше.

Фишка

Если Pin = 1.21·Pu (как в 8.2), то сразу η = 1/1.21 = 0.826. И потери = 0.21·Pu.

03

Функция потерь и максимум КПД

Потери делятся на два сорта. Постоянные Pc есть всегда, даже когда машина крутится вхолостую: подшипники, вентилятор. Переменные растут с нагрузкой: в моторе это нагрев обмоток током, а ток растёт с нагрузкой, тепло ∝ I², отсюда квадрат.

Ploss(x) = Pc + xn·Pv1n ≈ 1 механика · n ≈ 2 электромашины · n ≈ 3 насосы и вентиляторы

Подставляем всё в КПД и получаем КПД как функцию нагрузки (формула 7.0.1 из листка):

η(x) = x·Pnx·Pn + Pc + xn·Pv1

Где максимум

Делим числитель и знаменатель на x: η = Pn / (Pn + Pc/x + xn−1Pv1). КПД максимален, когда знаменатель минимален. Pc/x падает с ростом x, x·Pv1 растёт. Для n = 2 берём производную по x и приравниваем к нулю: −Pc/x² + Pv1 = 0. Отсюда:

n = 2:  xopt = √PcPv1оптимум там, где постоянные = переменным: Pc = x²Pv1
n = 3:  xopt = 3√Pc2Pv1n = 1: максимума нет, η только растёт с x

И ηmax = xoptPn / (xoptPn + 2Pc) для n = 2, потому что в оптимуме все потери равны 2Pc.

Как найти Pc и Pv1 из двух измерений

Это главный тип задач (7.3, 8.3). Дают две точки: нагрузку и КПД (или мощности). Рецепт:

1
В каждой точке находишь потери: Pu = x·Pn, Pin = Pu/η, Ploss = Pin − Pu.
2
Пишешь два уравнения: Ploss,1 = Pc + x1²Pv1 и Ploss,2 = Pc + x2²Pv1.
3
Вычитаешь одно из другого, Pc уходит: Pv1 = Ploss,1 − Ploss,2x1² − x2². Потом Pc из любого уравнения.
4
xopt = √(Pc/Pv1), ηmax по формуле выше.
Почему так

Если КПД одинаковый при двух нагрузках xa и xb (как в 8.3: 95 % и 95 %), то максимум ровно посередине «в геометрическом смысле»: xopt = √(xa·xb). Для 8.3: √(1·0.526) = 0.725. Проверка ответа на халяву.

04

Средний КПД и средняя нагрузка за цикл

Машина работает циклами: сначала пашет на полную, потом на половину, потом стоит вхолостую, пока меняют деталь. Спрашивают, какой КПД в среднем. Тут нельзя складывать КПД и делить на количество: интервалы разной длины и разной мощности. Правильно через работу (энергию):

ηavg = Σ Pu,i·tiΣ Pin,i·ti = WuWin
xavg = WuPn·T = Σ xi·tiT
Холостой ход

На холостом ходу x = 0: полезной работы нет, а вход есть. Для мотора вход на холостом ходу ≈ Pc (8.4: «constant loss (idle power) Pc = 0.5 kW»). Этот интервал входит в T и в Win, но ничего не добавляет в Wu. Поэтому долгий холостой ход убивает средний КПД.

05

Передачи, ворот и балансирная машина

Передача (зубчатая, червячная) меняет обороты и момент. Мощность при этом только теряется, но не появляется:

i = ω1ω2 = n1n2 = z2z11 = ведущее (мотор), 2 = ведомое (выход)
P2 = η·P1  ⇒  M2 = i·η·M1из P = M·ω: во сколько раз медленнее, во столько (почти) сильнее

Вывод второй формулы в одну строку: P2 = η P1 → M2ω2 = η M1ω1 → M2/M1 = η·ω1/ω2 = η·i. Отсюда в 7.1: отношение моментов 16 = i·0.64 → i = 25.

Ворот из 8.1 · крутится по-настоящему

Рукоятка крутится со скоростью ω = v/k = 1.75 1/с. Через две ступени (i = 5·5.3 = 26.5) барабан в 26.5 раз медленнее: 0.066 1/с. Груз едет со скоростью барабанного обода: vG = ω·r ≈ 9.9 мм/с. Поэтому 12 м поднимаешь 20 минут: выигрыш в силе, проигрыш в скорости.

Балансирная машина (7.3)

Статор мотора подвешен так, что может качаться. Мотор крутит вал, а статор по третьему закону Ньютона тянет в обратную сторону с тем же моментом. Этот момент уравновешивают грузиком m на плече k. Получается прямое измерение момента на валу.

M = (m − m0)·g·k,   Pu = M·ω,   Pin = U·Im₀ уравновешивает холостой ход (собственное трение), в полезный момент он не идёт

Шпора на одну страницу

Основа

Pin = Pu + Ploss

η = Pu/Pin · x = Pu/Pn

W = P·t · 1 кВт·ч = 3.6 МДж

Потери

Ploss = Pc + xⁿPv1

n: 1 механика · 2 электро · 3 насосы

η(x) = xPn/(xPn + Pc + xⁿPv1)

Оптимум

n = 2: xopt = √(Pc/Pv1), там Ploss = 2Pc

n = 3: xopt = ∛(Pc/2Pv1)

одинаковый η при xa, xb → xopt = √(xaxb)

Две точки → Pc, Pv1

Ploss = Pu/η − Pu в каждой

Pv1 = (L1 − L2)/(x1² − x2²), Pc = L2 − x2²Pv1

Цикл

ηavg = ΣPut / ΣPint

xavg = Σxiti / T
