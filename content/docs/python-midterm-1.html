Пузырьковая сортировка (была на практике 6)

Пузырьки в газировке: сравниваешь соседей и меняешь их местами, если стоят неправильно. После каждого прохода самый большой «всплывает» в конец. Если за проход не было ни одного обмена, всё уже отсортировано.
items = [12, 2, 4, 10, 6]
n = len(items)
for i in range(n - 1):
    swapped = False
    for j in range(n - 1 - i):        # хвост уже отсортирован, его не трогаем
        if items[j] > items[j + 1]:
            items[j], items[j + 1] = items[j + 1], items[j]
            swapped = True
    if not swapped:
        break
print(items)
[2, 4, 6, 10, 12]
Не удаляй элементы из списка, пока бежишь по нему for: элементы съезжают, и часть пропускается. Собери новый список: a = [x for x in a if x != 0].

ТерминПо-человечески
Interpreted languagePython не компилируется заранее в машинный код: интерпретатор читает и выполняет программу на ходу. Поэтому удобно, но медленнее, и многие ошибки всплывают только при запуске (runtime errors).
Von Neumann architectureCPU (управляющее устройство + АЛУ), память, ввод/вывод. Данные и команды лежат в одной памяти. У Harvard они раздельно.
Bit / byte, binary / hex1 байт = 8 бит. 1 kB = 1000 B, 1 KiB = 1024 B. Байт удобно писать двумя hex-цифрами: 0xFF = 255.

15. Центр масс и периметр практика 8

Пять одинаковых точечных масс в точках (кортежи). Найти центр масс и периметр многоугольника, который обходит точки по порядку и замыкается.

Подсказка
Центр масс одинаковых масс это просто среднее x и среднее y. Для замыкания соседом последней точки берут points[(i + 1) % n], то есть первую.
Решение
import math
points = [(0, 0), (4, 0), (5, 3), (2, 5), (-1, 3)]
n = len(points)
cx = sum(x for x, y in points) / n
cy = sum(y for x, y in points) / n
perimeter = 0
for i in range(n):
    x1, y1 = points[i]
    x2, y2 = points[(i + 1) % n]       # после последней снова первая
    perimeter += math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2)
print(f"центр масс: ({cx:.2f}, {cy:.2f}), периметр: {perimeter:.3f}")
центр масс: (2.00, 2.20), периметр: 17.536
