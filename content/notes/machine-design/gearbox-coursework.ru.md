## Что обычно дано

Привод конвейера (или лебёдки): тяговое усилие $F_t$ на барабане или звёздочке, скорость ленты $v$, диаметр барабана $D$, срок службы, режим работы. Схема: двигатель → (ремённая передача) → двухступенчатый цилиндрический редуктор → муфта → приводной вал.

## Шаг 1. Кинематический и энергетический расчёт

1. Мощность на выходе: $P_\text{вых} = F_t v$.
2. Общий КПД привода: $\eta = \eta_\text{рем}\eta_\text{зуб}^2\eta_\text{подш}^k\eta_\text{муфты}$ (ремень 0.95–0.97, зубчатая пара 0.97–0.98, пара подшипников 0.99, муфта 0.98).
3. Требуемая мощность двигателя: $P_\text{тр} = P_\text{вых}/\eta$. Выбираем асинхронный двигатель (серия АИР) с $P_\text{ном} \ge P_\text{тр}$.
4. Частота вращения выходного вала: $n_\text{вых} = \dfrac{60\,000\,v}{\pi D}$ ($v$ в м/с, $D$ в мм).
5. Общее передаточное: $u = n_\text{дв}/n_\text{вых}$. Перебираем двигатели с синхронными 750/1000/1500/3000 об/мин и выбираем тот, где $u$ разумно разбивается.
6. Разбивка по ступеням. Для двухступенчатого редуктора по развёрнутой схеме $u_\text{б} \approx (1.2\dots1.3)u_\text{т}$ (быстроходная ступень чуть больше), так колёса окунаются в масло примерно одинаково. Подгоняем под стандартные значения.
7. Для каждого вала: мощность $P_i$, обороты $n_i$, момент $T_i = 9550P_i/n_i$. Свести в **таблицу**, она понадобится везде.

## Шаг 2. Материалы и допускаемые напряжения

Выбираем сталь и ТО для шестерён и колёс (типично `40Х`, улучшение: шестерня 270–300 HB, колесо 240–270 HB; для компактности ТВЧ или цементация). Считаем $[\sigma_H]$ и $[\sigma_F]$ с учётом числа циклов (через срок службы и обороты).

## Шаг 3. Расчёт тихоходной ступени (начинаем с неё, она самая нагруженная)

1. Межосевое расстояние по контактной прочности: $a_w \ge K_a(u + 1)\sqrt[3]{\dfrac{T_2K_H}{\psi_{ba}u^2[\sigma_H]^2}}$, округлить по ГОСТ 2185.
2. Модуль $m_n = (0.01\dots0.02)a_w$, округлить по ГОСТ 9563.
3. Угол наклона (косозубые) $\beta = 8\dots18°$, суммарное число зубьев $z_\Sigma = \dfrac{2a_w\cos\beta}{m_n}$, округлить вниз, уточнить $\beta$.
4. $z_1 = z_\Sigma/(u + 1)$, $z_2 = z_\Sigma - z_1$. Проверить $z_1 \ge 17$ (иначе смещение).
5. Фактическое $u$, отклонение от заданного $\le 2.5$–4%.
6. Диаметры $d$, $d_a$, $d_f$, ширины $b_2 = \psi_{ba}a_w$, $b_1 = b_2 + (3\dots5)$ мм.
7. Окружная скорость → **степень точности** (обычно 8 или 9 по ГОСТ 1643).
8. Проверка контактных напряжений (недогруз до 10–15%, перегруз до 5% допускается), проверка изгиба.
9. Силы в зацеплении $F_t$, $F_r$, $F_a$.

## Шаг 4. Расчёт быстроходной ступени

То же самое. В соосной схеме $a_w$ быстроходной ступени принимают равным тихоходной.

## Шаг 5. Ремённая (цепная) передача, если есть

Для клиновых ремней: сечение по моменту и оборотам, диаметр малого шкива, межосевое, длина ремня по стандарту, угол обхвата $\ge 120°$, число ремней, сила на вал.

## Шаг 6. Предварительный расчёт валов и эскизная компоновка

1. Диаметры по кручению с $[\tau] = 15\dots25$ МПа, согласование входного вала с валом двигателя (муфта!).
2. Предварительный выбор подшипников (обычно лёгкая серия шариковых радиальных или конических для косозубых).
3. **Эскизная компоновка** на миллиметровке или в КОМПАС/SolidWorks: зазоры между колёсами и корпусом ($a \approx \sqrt[3]{L} + 3$ мм, где $L$ наибольший габарит), положение подшипников, длины ступеней. Из неё берём расстояния для эпюр.

## Шаг 7. Проверочный расчёт валов

Расчётные схемы в двух плоскостях, реакции, эпюры $M_x$, $M_y$, $T$, опасные сечения, коэффициенты запаса по усталости $s \ge 1.5\dots2.5$.

## Шаг 8. Подшипники

Эквивалентные нагрузки с учётом осевых сил (для конических и радиально-упорных учитывать осевые составляющие $S = eF_r$ от радиальных), ресурс $L_{10h}$ $\ge$ требуемого.

## Шаг 9. Шпонки, муфты, посадки

- Шпонки под колёсами и на концах валов на смятие.
- Муфта по расчётному моменту $T_p = K T$ ($K = 1.2\dots2$), упругая втулочно-пальцевая (МУВП) или с торообразной оболочкой на входе, зубчатая или цепная на выходе.
- Посадки: колесо на вал `H7/r6` или `H7/p6`, внутреннее кольцо подшипника на вал k6 (при циркуляционном нагружении), наружное в корпус H7, крышки H7/h8 или H7/d11.

## Шаг 10. Корпус, смазка, уплотнения

Литой чугунный корпус (СЧ15): толщина стенки $\delta \approx 0.025a_w + 3 \ge 8$ мм. Смазка окунанием: колесо тихоходной ступени погружено на 1–2 высоты зуба, но не больше $1/4$ радиуса. Объём масла ≈ 0.4–0.8 л на 1 кВт. Марка масла по вязкости в зависимости от контактных напряжений и скорости (типично И-Г-А-46/68). Уплотнения: манжеты ГОСТ 8752.

## Шаг 11. Чертежи и пояснительная записка

- **Сборочный чертёж** редуктора (2–3 вида, разрезы), спецификация.
- **Чертёж общего вида** привода.
- **Рабочие чертежи** вала и колеса (с допусками, шероховатостью, допусками формы и расположения, техническими требованиями).
- Записка по ГОСТ 7.32 / 2.105 с расчётами.

## Чек-лист частых ошибок

- [ ] Моменты считали по мощности **на этом валу**, а не на двигателе.
- [ ] Передаточное разбито так, что колесо быстроходной ступени не задевает тихоходный вал.
- [ ] $a_w$, $m$, $u$ округлены по **стандартным** рядам, фактическое $u$ пересчитано.
- [ ] $z_1 \ge 17$, иначе подрезание.
- [ ] Ширина шестерни больше ширины колеса на 3–5 мм.
- [ ] Ступени вала растут к середине, есть буртики для упора колёс и подшипников, подшипник надевается без прохода через посадку колеса.
- [ ] Диаметр входного вала согласован с муфтой и валом двигателя.
- [ ] Учтены **осевые силы** от косозубых колёс в эпюрах и в подборе подшипников.
- [ ] Консольная сила от муфты/ремня на выходном конце вала не забыта.
- [ ] Посадки подшипников по ГОСТ 3325 (на вал k6/js6, в корпус H7), а не H7/p6.
- [ ] Смазка: колесо достаёт до масла, но не тонет в нём.
- [ ] На рабочем чертеже вала есть радиусы галтелей, фаски, канавки для выхода шлифовального круга и центровые отверстия.
- [ ] В спецификации стандартные изделия по ГОСТ с полными обозначениями.

```calc
F = 3 | 0.5..20 | кН | Тяговое усилие
v = 1.2 | 0.2..3 | м/с | Скорость ленты
D = 300 | 100..800 | мм | Диаметр барабана
nd = 1450 | 700..2900 | об/мин | Обороты двигателя
eta = 0.97^2*0.99^3*0.98 | | | КПД (2 пары, 3 пары подшипников, муфта)
Pout = F*v | | кВт | Мощность на барабане
Preq = Pout/eta | | кВт | Требуемая мощность двигателя
nout = 60000*v/(pi*D) | | об/мин | Обороты барабана
u = nd/nout | | | Общее передаточное
ut = sqrt(u/1.25) | | | Тихоходная ступень
ub = u/ut | | | Быстроходная ступень
Tout = 9550*Pout/nout | | Н·м | Момент на барабане
```
