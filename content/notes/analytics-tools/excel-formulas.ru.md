## Ссылки и знак доллара

- `A1` относительная: при копировании формулы сдвигается.
- `$A$1` абсолютная: не сдвигается никогда.
- `$A1` закреплён столбец, `A$1` закреплена строка. Классика: таблица умножения `=$A2*B$1`.

Клавиша **F4** перебирает варианты. В Google Таблицах то же самое.

Названия функций в русском Excel переведены, в Google Таблицах работают английские. Ниже даю оба варианта.

## Логика и условные суммы

| Задача | Русский Excel | Английский |
|---|---|---|
| Условие | `=ЕСЛИ(B2>100;"крупный";"мелкий")` | `=IF(B2>100,"big","small")` |
| Несколько условий | `=ЕСЛИМН(B2>1000;"A";B2>100;"B";ИСТИНА;"C")` | `=IFS(...)` |
| И / ИЛИ | `=И(B2>0;C2="да")` | `=AND(...)`, `=OR(...)` |
| Перехват ошибки | `=ЕСЛИОШИБКА(A2/B2;0)` | `=IFERROR(A2/B2,0)` |
| Сумма по условиям | `=СУММЕСЛИМН(D:D;A:A;"Москва";B:B;">=2026-01-01")` | `=SUMIFS(...)` |
| Количество по условию | `=СЧЁТЕСЛИМН(A:A;"Москва")` | `=COUNTIFS(...)` |
| Среднее по условию | `=СРЗНАЧЕСЛИМН(D:D;A:A;"Москва")` | `=AVERAGEIFS(...)` |

Разделитель аргументов в русской локали `;`, в английской `,`.

## Поиск значений

### ВПР (VLOOKUP)

`=ВПР(искомое; таблица; номер_столбца; ЛОЖЬ)` ищет значение в **первом** столбце таблицы и возвращает значение из столбца с указанным номером.

Ловушки:
- Последний аргумент **обязательно ЛОЖЬ** (точное совпадение). Без него Excel ищет приблизительно по отсортированному списку и молча возвращает чушь.
- Не умеет искать **левее** ключа.
- Номер столбца захардкожен: вставил столбец, формула поехала.

### ИНДЕКС + ПОИСКПОЗ

`=ИНДЕКС(C:C; ПОИСКПОЗ(F2; A:A; 0))`. ПОИСКПОЗ находит **номер строки** ключа, ИНДЕКС берёт значение из нужного столбца по этому номеру. Ищет в любую сторону, не ломается от вставки столбцов. Английский вариант `=INDEX(C:C, MATCH(F2, A:A, 0))`.

### ПРОСМОТРX (XLOOKUP)

Современная замена всему этому (Excel 2021/365 и Google Таблицы):

`=ПРОСМОТРX(F2; A:A; C:C; "не найдено")`

Ищет в любую сторону, точное совпадение по умолчанию, свой текст при отсутствии значения, умеет искать с конца.

## Текст и даты

| Задача | Формула |
|---|---|
| Склеить | `=A2&" "&B2` или `=СЦЕП(A2;" ";B2)` / `CONCAT` |
| Убрать лишние пробелы | `=СЖПРОБЕЛЫ(A2)` / `TRIM` |
| Часть строки | `=ЛЕВСИМВ(A2;3)`, `=ПСТР(A2;4;2)` / `LEFT`, `MID` |
| Разбить по разделителю | `=ТЕКСТРАЗД(A2;",")` / `TEXTSPLIT`, в Google `SPLIT` |
| Число как текст с форматом | `=ТЕКСТ(A2;"0,00 ₽")` / `TEXT` |
| Конец месяца | `=КОНМЕСЯЦА(A2;0)` / `EOMONTH` |
| Рабочих дней между датами | `=ЧИСТРАБДНИ(A2;B2)` / `NETWORKDAYS` |

Дата в Excel это **число дней** с 1900 года, поэтому даты можно вычитать: `=B2-A2` даст число дней.

## Финансовые функции

| Задача | Формула | Ловушка |
|---|---|---|
| NPV | `=ЧПС(ставка; CF1:CFn) + CF0` | ЧПС дисконтирует **первый** аргумент на один период, поэтому инвестицию на $t = 0$ прибавляют снаружи |
| IRR | `=ВСД(CF0:CFn)` | потоки строго через равные периоды |
| NPV и IRR по датам | `=ЧИСТНЗ(ставка; потоки; даты)`, `=ЧИСТВНДОХ(...)` / `XNPV`, `XIRR` | ставка годовая, даты реальные |
| Платёж по кредиту | `=ПЛТ(ставка/12; срок*12; -сумма)` / `PMT` | знак: деньги, которые получаешь, «+», платишь «−» |
| Будущая стоимость | `=БС(ставка; n; платёж; -PV)` / `FV` | |

Пример проверки с конспектом про кредит: `=ПЛТ(12%/12; 240; -3000000)` даёт 33 033 ₽.

## Сводные таблицы

**Сводная** за пару кликов группирует и агрегирует данные: выдели таблицу, Вставка → Сводная таблица, перетащи поля в **Строки**, **Столбцы**, **Значения** (сумма, количество, среднее) и **Фильтры**.

Чтобы сводная работала:
- данные в виде **плоской таблицы**: одна строка это одна запись, один столбец это одно поле, заголовки в одну строку;
- никаких объединённых ячеек и промежуточных итогов внутри данных;
- оформи данные как **Таблицу** (Ctrl+T), тогда новые строки подхватятся автоматически.

Сводная в SQL это `GROUP BY`; см. конспект про SQL.

## Правила хорошей модели

1. **Входные данные отдельно** от расчётов, на своём листе, другим цветом (обычно синие цифры это ввод, чёрные это формулы).
2. **Никаких чисел внутри формул**: не `=B2*1.2`, а `=B2*(1+НДС)`, где НДС это именованная ячейка.
3. Одна формула на всю строку или столбец, без ручных правок посередине.
4. **Проверки**: баланс сходится, сумма по месяцам равна году; выведи их в отдельные ячейки с условным форматированием.
5. Не используй ЕСЛИОШИБКА, чтобы прятать ошибки, которые надо чинить.

## Карточки

```cards
$A$1 :: абсолютная ссылка, не сдвигается при копировании
Последний аргумент ВПР :: ЛОЖЬ, точное совпадение
Чем ИНДЕКС+ПОИСКПОЗ лучше ВПР :: ищет влево и не ломается от вставки столбцов
ПРОСМОТРX :: XLOOKUP, современный поиск с точным совпадением по умолчанию
Ловушка ЧПС :: инвестицию на t = 0 прибавляют вне функции
ЧИСТНЗ :: XNPV, NPV по реальным датам
СУММЕСЛИМН :: SUMIFS, сумма по нескольким условиям
Условие для сводной таблицы :: плоская таблица, одна строка на запись
```

## Проверь себя

```quiz
? Потоки: −1000 в начале, затем 600 и 600. Какая формула даст верный NPV при 10%?
- =ЧПС(10%;−1000;600;600)
+ =ЧПС(10%;600;600)−1000
> В первом варианте инвестиция тоже дисконтируется, и NPV получится занижен в 1.1 раза.

? Формула =B$2*$A3 скопирована вправо на один столбец. Что получится?
+ =C$2*$A3
- =B$2*$B3
- =C$3*$A4

? Ключ в столбце D, ответ нужен из столбца B. Что не сработает?
+ ВПР
- ИНДЕКС+ПОИСКПОЗ
- ПРОСМОТРX
```
