## Термический КПД

Любой цикл тепловой машины получает тепло $q_1$ от горячего источника, отдаёт $q_2$ холодному и производит работу $l = q_1 - q_2$:

$$\eta_t = \frac{l}{q_1} = 1 - \frac{q_2}{q_1}.$$

## Цикл Карно: потолок

Две изотермы и две адиабаты. КПД зависит **только от температур** источников:

$$\eta_\text{Карно} = 1 - \frac{T_2}{T_1}.$$

Никакая машина между теми же температурами не может быть эффективнее. Пример: $T_1 = 1500$ К, $T_2 = 300$ К дают $\eta \le 80\%$. Реальные машины до этого не дотягивают из-за необратимостей, а сам цикл Карно на газе непрактичен (огромные давления при крошечной работе).

**Холодильник и тепловой насос** работают по обратному циклу. Холодильный коэффициент Карно $\varepsilon = \dfrac{T_2}{T_1 - T_2}$, отопительный $\varphi = \dfrac{T_1}{T_1 - T_2}$. Тепловой насос между 0 °C и 40 °C в идеале даёт до ~7.8 кВт тепла на 1 кВт электричества.

## Цикл Отто (бензиновый ДВС)

1–2 адиабатное сжатие, 2–3 подвод тепла при $v = \text{const}$ (мгновенное сгорание от свечи), 3–4 адиабатное расширение, 4–1 отвод тепла при $v = \text{const}$ (выпуск).

$$\eta_\text{Отто} = 1 - \frac{1}{\varepsilon^{k-1}}, \qquad \varepsilon = \frac{v_1}{v_2}\ \text{(степень сжатия)}.$$

КПД растёт со степенью сжатия, но её ограничивает **детонация**: при $\varepsilon \approx 10$–12 смесь воспламеняется сама. Поэтому октановое число бензина так важно.

## Цикл Дизеля

Подвод тепла при $p = \text{const}$ (топливо впрыскивается и горит по мере подачи). Сжимается только воздух, детонации нет, $\varepsilon = 16$–22.

$$\eta_\text{Дизель} = 1 - \frac{1}{\varepsilon^{k-1}}\cdot\frac{\rho^k - 1}{k(\rho - 1)}, \qquad \rho = \frac{v_3}{v_2}\ \text{(степень предварительного расширения)}.$$

При одинаковом $\varepsilon$ Отто эффективнее, но дизель выигрывает за счёт куда большей допустимой степени сжатия. Реальные современные дизели работают по смешанному циклу **Тринклера** (часть тепла при $v = \text{const}$, часть при $p = \text{const}$).

## Цикл Брайтона (газовая турбина)

Компрессор (адиабатное сжатие) → камера сгорания ($p = \text{const}$) → турбина (адиабатное расширение) → выброс ($p = \text{const}$).

$$\eta_\text{Брайтон} = 1 - \frac{1}{\pi^{(k-1)/k}}, \qquad \pi = \frac{p_2}{p_1}\ \text{(степень повышения давления)}.$$

Современные авиадвигатели имеют $\pi \approx 40$–50. Ограничение: температура перед турбиной (жаропрочность лопаток), поэтому лопатки охлаждают и покрывают керамикой. Регенерация (подогрев воздуха выхлопом) и комбинированный цикл (газ + пар, ПГУ) поднимают КПД электростанций до ~60%.

## Цикл Ренкина (паросиловая установка)

Рабочее тело это вода и пар с фазовыми переходами: насос сжимает воду → котёл нагревает, испаряет и перегревает пар ($p = \text{const}$) → турбина расширяет пар → конденсатор превращает его обратно в воду.

$$\eta_\text{Ренкин} = \frac{(h_1 - h_2) - (h_4 - h_3)}{h_1 - h_4} \approx \frac{h_1 - h_2}{h_1 - h_3},$$

где $h_1$ перед турбиной, $h_2$ после турбины, $h_3$ конденсат, $h_4$ после насоса. Работа насоса крошечная, потому что вода почти несжимаема (это главное преимущество над газовыми циклами). Энтальпии берут из **h-s диаграммы** (Молье) или таблиц водяного пара (IAPWS-IF97, Python: библиотеки `iapws`, `CoolProp`).

КПД повышают: выше начальные параметры пара (сверхкритические, 25–30 МПа, 600 °C), ниже давление в конденсаторе (глубокий вакуум), **промперегрев** и **регенеративный подогрев** питательной воды отборами пара.

## Сравнение на живых графиках

```calc
eps = 10 | 2..25 | | Степень сжатия ε
k = 1.4 | 1.2..1.67 | | Показатель адиабаты
rho = 2 | 1.1..4 | | Предварительное расширение ρ (Дизель)
etaOtto = (1 - 1/eps^(k - 1))*100 | | % | КПД Отто
etaDiesel = (1 - (rho^k - 1)/(k*(rho - 1)*eps^(k - 1)))*100 | | % | КПД Дизеля
plot e: 2..25 | (1 - 1/e^(k - 1))*100 | Отто
plot e: 2..25 | (1 - (rho^k - 1)/(k*(rho - 1)*e^(k - 1)))*100 | Дизель
axes: ε ; η, %
```

```calc
k = 1.4 | 1.2..1.67 | | Показатель адиабаты
pr = 20 | 2..60 | | Степень повышения давления π
eta = (1 - 1/pr^((k - 1)/k))*100 | | % | КПД Брайтона
plot x: 2..60 | (1 - 1/x^((k - 1)/k))*100 | η(π)
axes: π ; η, %
```

## Карточки

```cards
Термический КПД цикла :: $\eta = 1 - q_2/q_1$
КПД Карно :: $1 - T_2/T_1$
КПД Отто :: $1 - 1/\varepsilon^{k-1}$
КПД Брайтона :: $1 - 1/\pi^{(k-1)/k}$
Подвод тепла в цикле Отто :: при $v = \text{const}$
Подвод тепла в цикле Дизеля :: при $p = \text{const}$
Что ограничивает $\varepsilon$ в бензиновом ДВС :: детонация
Что ограничивает газовую турбину :: температура перед турбиной
Почему насос в цикле Ренкина почти не тратит работу :: вода почти несжимаема
Холодильный коэффициент Карно :: $T_2 / (T_1 - T_2)$
```

## Проверь себя

```quiz
? Как поднять КПД Карно эффективнее: на 100 К повысить $T_1$ или на 100 К понизить $T_2$?
- повысить $T_1$
+ понизить $T_2$
- одинаково
> $\partial\eta/\partial T_2 = -1/T_1$ по модулю больше, чем $\partial\eta/\partial T_1 = T_2/T_1^2$.

? При одинаковой степени сжатия КПД какого цикла выше?
+ Отто
- Дизеля
- одинаковый

? Из чего берут энтальпии для цикла Ренкина?
- из уравнения $pv = RT$
+ из таблиц или h-s диаграммы водяного пара
- из формулы Карно
```
