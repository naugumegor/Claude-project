## Денежные потоки проекта

Проект описывают **денежными потоками** (cash flows, CF) по периодам: $CF_0$ это обычно инвестиция со знаком минус, дальше идут поступления минус выплаты. Считают именно **деньги**, а не прибыль: амортизация это не отток денег, а вот покупка станка и прирост оборотного капитала это отток.

Свободный денежный поток проекта (упрощённо):

$$FCF = EBIT(1 - t) + \text{Амортизация} - \text{CAPEX} - \Delta\text{ОК}.$$

## NPV: чистая приведённая стоимость

$$NPV = \sum_{t=0}^{n}\frac{CF_t}{(1 + r)^t} = -I_0 + \frac{CF_1}{1 + r} + \frac{CF_2}{(1 + r)^2} + \dots$$

- $NPV > 0$: проект создаёт стоимость сверх требуемой доходности, **принимаем**.
- $NPV < 0$: деньги лучше вложить в альтернативу с тем же риском.
- Из нескольких взаимоисключающих проектов выбираем проект с **наибольшим NPV**.

NPV аддитивен: NPV двух проектов равен сумме их NPV. Поэтому его любят финансисты.

## IRR: внутренняя норма доходности

**IRR** это ставка, при которой $NPV = 0$:

$$\sum_{t=0}^{n}\frac{CF_t}{(1 + IRR)^t} = 0.$$

Это «доходность проекта в процентах». Правило: принимаем, если $IRR > r$ (ставки дисконтирования).

Считается только численно (подбором, методом Ньютона, в Excel `=ВСД()` / `=IRR()`).

Ловушки IRR:
- При **нестандартных потоках** (минус, плюс, снова минус) может быть несколько IRR или ни одной.
- При сравнении проектов разного масштаба IRR врёт: 50% на 1000 ₽ хуже, чем 20% на миллион. **При конфликте NPV и IRR побеждает NPV.**
- IRR неявно предполагает реинвестирование потоков по ставке IRR. Модифицированная **MIRR** это исправляет.

## Срок окупаемости

**Простой** (PP): за сколько лет сумма поступлений покроет инвестицию. Прост и понятен, но игнорирует стоимость денег во времени и всё, что после окупаемости.

**Дисконтированный** (DPP): то же, но по дисконтированным потокам. Всегда длиннее простого.

## Индекс рентабельности

$$PI = \frac{\sum_{t\ge1} CF_t/(1 + r)^t}{I_0}.$$

$PI > 1$ равносильно $NPV > 0$. Полезен при **ограниченном бюджете**: ранжируем проекты по PI и набираем, пока хватает денег.

## Откуда брать ставку дисконтирования

### WACC: средневзвешенная стоимость капитала

Компания финансируется собственным капиталом $E$ и долгом $D$. Требуемая доходность в среднем:

$$WACC = \frac{E}{E + D}r_E + \frac{D}{E + D}r_D(1 - t).$$

Множитель $(1 - t)$ это **налоговый щит**: проценты по долгу уменьшают налог на прибыль. Долг почти всегда дешевле собственного капитала (кредитор рискует меньше акционера), но слишком много долга повышает риск банкротства, и обе ставки растут.

### CAPM: стоимость собственного капитала

$$r_E = r_f + \beta(r_m - r_f).$$

$r_f$ безрисковая ставка (гособлигации), $r_m - r_f$ рыночная премия за риск (исторически 4–7%), $\beta$ чувствительность акции к рынку (1 = как рынок, > 1 = рискованнее).

Пример: $r_f = 12\%$, $\beta = 1.2$, премия 7% → $r_E = 20.4\%$. Долг под 14%, налог 20%, структура E:D = 60:40 → $WACC = 0.6\cdot20.4 + 0.4\cdot14\cdot0.8 = 16.7\%$.

Для рискованных проектов (новый рынок, стартап) к WACC добавляют **премию за специфический риск**.

## Пример

Станок с ЧПУ: инвестиция 10 млн ₽, экономия 3 млн ₽ в год в течение 5 лет, ставка 15%.

$$NPV = -10 + \frac{3}{1.15} + \frac{3}{1.15^2} + \dots + \frac{3}{1.15^5} = -10 + 3\cdot3.352 = 0.06\ \text{млн}.$$

Еле-еле в плюсе. IRR ≈ 15.2%, простая окупаемость 3.3 года, дисконтированная почти 5 лет. Любое ухудшение (выручка ниже на 5%) уводит проект в минус. Поэтому всегда делают **анализ чувствительности**: двигают ключевые параметры и смотрят, где NPV переходит через ноль.

```calc
title: NPV проекта на 5 лет
I0 = 10 | 1..100 | млн ₽ | Инвестиция
CF = 3 | 0..30 | млн ₽/год | Поток в год
g = 0 | -20..20 | %/год | Рост потока
r = 15 | 1..40 | % | Ставка дисконтирования
q = 1 + g/100 | | | Множитель роста
PVsum = CF*(1/(1 + r/100) + q/(1 + r/100)^2 + q^2/(1 + r/100)^3 + q^3/(1 + r/100)^4 + q^4/(1 + r/100)^5) | | млн ₽ | Сумма приведённых потоков
NPV = PVsum - I0 | | млн ₽ | NPV
PI = PVsum/I0 | | | Индекс рентабельности
plot x: 1..40 | CF*(1/(1 + x/100) + q/(1 + x/100)^2 + q^2/(1 + x/100)^3 + q^3/(1 + x/100)^4 + q^4/(1 + x/100)^5) - I0 | NPV(ставка)
axes: ставка, % ; NPV, млн ₽
```

Где график пересекает ноль, там IRR.

То же самое для произвольных потоков (впиши свои через запятую):

```tool
name: cashflow
rate: 15
flows: -10, 3, 3, 3, 3, 3
```

```python
import numpy as np
from scipy.optimize import brentq

cf = np.array([-10, 3, 3, 3, 3, 3], dtype=float)  # млн ₽
t = np.arange(len(cf))
npv = lambda r: np.sum(cf / (1 + r) ** t)

r = 0.15
irr = brentq(npv, -0.9, 1.0)
disc = cf / (1 + r) ** t
dpp = np.argmax(np.cumsum(disc) >= 0)
print(f"NPV = {npv(r):.3f} млн, IRR = {irr:.2%}, дисконтированная окупаемость ≈ {dpp} лет")

# Чувствительность NPV к потоку и ставке
for dcf in (-0.10, -0.05, 0, 0.05, 0.10):
    row = [np.sum(np.r_[cf[0], cf[1:] * (1 + dcf)] / (1 + rr) ** t) for rr in (0.12, 0.15, 0.18)]
    print(f"поток {dcf:+.0%}: " + "  ".join(f"{v:+.2f}" for v in row))
```

## Карточки

```cards
NPV :: $\sum CF_t/(1 + r)^t$
Правило NPV :: принимаем при $NPV > 0$
IRR :: ставка, при которой $NPV = 0$
Что побеждает при конфликте NPV и IRR :: NPV
Индекс рентабельности :: $PI = PV(\text{поступлений})/I_0$
WACC :: $\frac{E}{V}r_E + \frac{D}{V}r_D(1 - t)$
CAPM :: $r_E = r_f + \beta(r_m - r_f)$
Налоговый щит :: проценты по долгу уменьшают налог, отсюда $(1 - t)$
Чем дисконтированная окупаемость отличается от простой :: учитывает стоимость денег во времени, всегда длиннее
Почему амортизацию не вычитают из денежного потока :: это не отток денег
```
