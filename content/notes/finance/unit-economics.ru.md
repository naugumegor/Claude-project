## Зачем это

**Юнит-экономика** считает прибыль на одну «единицу»: одного клиента, один заказ, одну подписку. Если на единице бизнес теряет деньги, рост его только быстрее убьёт. Масштабировать можно только то, что в плюсе на уровне юнита.

Сначала реши, **что такое юнит**. Для интернет-магазина это обычно заказ или покупатель, для подписки (SaaS, онлайн-школа) это платящий клиент, для такси это поездка.

## Основные метрики

| Метрика | Формула | Смысл |
|---|---|---|
| [[CAC]] | $\dfrac{\text{расходы на привлечение}}{\text{новые клиенты}}$ | сколько стоит привести одного клиента |
| ARPU | $\dfrac{\text{выручка}}{\text{клиенты}}$ за период | средняя выручка с клиента |
| AOV (средний чек) | $\dfrac{\text{выручка}}{\text{заказы}}$ | |
| Маржинальность $m$ | $\dfrac{\text{выручка} - \text{переменные затраты}}{\text{выручка}}$ | доля выручки, которая остаётся после себестоимости |
| [[Churn]] $c$ | $\dfrac{\text{ушедшие за месяц}}{\text{клиенты на начало}}$ | отток |
| Конверсия CR | $\dfrac{\text{покупатели}}{\text{посетители}}$ | |

В CAC включай **всё**, что тратится на привлечение: рекламу, зарплату маркетологов и продажников, комиссии партнёров. Самая частая ошибка новичка это считать CAC только по рекламному бюджету.

## LTV: пожизненная ценность клиента

[[LTV]] (lifetime value) это валовая прибыль, которую клиент принесёт за всё время, пока с тобой.

Для подписки с постоянным оттоком $c$ в месяц средний срок жизни клиента равен $1/c$ месяцев (это матожидание геометрического распределения). Отсюда

$$LTV = \frac{ARPU\cdot m}{c}.$$

Для магазина: $LTV = AOV\cdot m\cdot(\text{среднее число покупок за жизнь})$.

**Важно**: LTV считай по **марже**, а не по выручке. Выручка в LTV даёт красивую, но лживую цифру.

## Главные проверки

1. $\dfrac{LTV}{CAC} > 3$: классический ориентир для здорового бизнеса. Около 1 значит, что ты работаешь бесплатно. Сильно больше 5 часто значит, что ты недовкладываешь в рост.
2. **Срок окупаемости CAC**: $\dfrac{CAC}{ARPU\cdot m}$ месяцев. Хорошо меньше 12 месяцев. Даже если LTV/CAC отличный, длинная окупаемость съедает оборотные деньги: ты платишь сейчас, а получаешь через год.
3. **Contribution margin** на юнит (вклад в покрытие постоянных затрат) должен быть положительным.

## Пример: онлайн-школа

ARPU 1500 ₽ в месяц, маржинальность 70% (остальное платформа, кураторы, эквайринг), отток 5% в месяц, CAC 9000 ₽.

- Средний срок жизни: $1/0.05 = 20$ месяцев.
- $LTV = 1500\cdot0.7/0.05 = 21\,000$ ₽.
- $LTV/CAC = 21\,000/9000 \approx 2.3$, ниже ориентира 3.
- Окупаемость CAC: $9000/1050 \approx 8.6$ месяца.

Что можно делать: снизить отток до 3% (LTV станет 35 000, отношение 3.9), поднять цену, удешевить привлечение через рефералку. Подвигай ползунки и посмотри, какой рычаг сильнее.

```calc
title: Юнит-экономика подписки
ARPU = 1500 | 100..10000..50 | ₽/мес | Выручка с клиента
m = 70 | 10..95 | % | Маржинальность
c = 5 | 1..30..0.5 | %/мес | Отток
CAC = 9000 | 0..50000..100 | ₽ | Стоимость привлечения
life = 100/c | | мес | Средний срок жизни
LTV = ARPU*m/c | | ₽ | LTV
ratio = LTV/CAC | | | LTV / CAC
payback = CAC/(ARPU*m/100) | | мес | Окупаемость CAC
plot t: 0..36 | ARPU*m/100*(1 - (1 - c/100)^t)/(c/100) - CAC | Накопленная прибыль с когорты на 1 клиента, ₽

```


## Пример: интернет-магазин

10 000 посетителей с рекламы за 200 000 ₽, конверсия 2%, средний чек 3000 ₽, маржинальность 30%.

- Покупателей: $10\,000\cdot0.02 = 200$, значит $CAC = 200\,000/200 = 1000$ ₽.
- Валовая прибыль с одного заказа: $3000\cdot0.3 = 900$ ₽.
- **Первый заказ убыточен**: $900 - 1000 = -100$ ₽.
- Если покупатель в среднем делает 2.5 заказа за жизнь, $LTV = 2250$ ₽, и юнит в плюсе на 1250 ₽.

Вывод: магазин живёт на повторных покупках, поэтому ему важнее CRM, рассылки и программа лояльности, чем ещё один рекламный канал.

## ROI и ROMI

$$ROI = \frac{\text{доход} - \text{вложения}}{\text{вложения}}\cdot100\%.$$

**ROMI** это ROI маркетинга: $\dfrac{\text{валовая прибыль от кампании} - \text{затраты на кампанию}}{\text{затраты на кампанию}}$. Считай по прибыли, а не по выручке, иначе любая кампания покажется прибыльной.

ROI не учитывает **время**: 50% за месяц и 50% за пять лет дают одинаковый ROI. Для длинных проектов бери NPV и IRR (см. конспект про оценку инвестиций).

## Типичные ошибки

- LTV по выручке, а не по марже.
- CAC без зарплат отдела продаж.
- Средний отток по всей базе вместо **когорт**: старые клиенты уходят реже новых, и среднее врёт.
- Смешивание каналов: в одном канале CAC 500 ₽, в другом 5000 ₽, а в среднем всё «нормально».
- LTV за 10 лет для стартапа, которому 8 месяцев. Ограничивай горизонт (например, 24–36 месяцев) и дисконтируй.

## Карточки

```cards
CAC :: все расходы на привлечение / число новых клиентов
LTV подписки :: $ARPU\cdot m / c$
Средний срок жизни клиента при оттоке $c$ :: $1/c$ периодов
Ориентир LTV/CAC :: больше 3
Окупаемость CAC :: $CAC / (ARPU\cdot m)$, хорошо меньше 12 месяцев
ROI :: (доход − вложения) / вложения
Почему LTV считают по марже :: выручка включает себестоимость, это не твои деньги
Когортный анализ :: отток и выручка по группам клиентов, пришедших в один месяц
```

## Проверь себя

```quiz
? ARPU 2000 ₽/мес, маржа 50%, отток 10%/мес. Чему равен LTV?
- 20 000 ₽
+ 10 000 ₽
- 1 000 ₽
> $2000\cdot0.5/0.1 = 10\,000$.

? LTV/CAC = 6, окупаемость CAC 30 месяцев. Что не так?
+ деньги возвращаются слишком медленно, нужен большой оборотный капитал
- всё отлично
- CAC слишком мал
> Высокое отношение не спасает, если каждый клиент окупается 2.5 года.

? Что сильнее всего поднимает LTV при оттоке 20%/мес?
- скидка на первый месяц
+ снижение оттока
- реклама в новом канале
> LTV обратно пропорционален оттоку: снизить его с 20% до 10% значит удвоить LTV.
```
