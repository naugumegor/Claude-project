## Кручение круглого вала

Внутренняя сила: **крутящий момент** $T$ (в старых учебниках $M_к$). Касательные напряжения растут линейно от центра:

$$\tau = \frac{T\rho}{I_p}, \qquad \tau_{\max} = \frac{T}{W_p}.$$

| Сечение | $I_p$ | $W_p$ |
|---|---|---|
| Круг $d$ | $\pi d^4/32$ | $\pi d^3/16 \approx 0.2d^3$ |
| Кольцо $D$, $c = d/D$ | $\frac{\pi D^4}{32}(1 - c^4)$ | $\frac{\pi D^3}{16}(1 - c^4)$ |

**Угол закручивания**:

$$\varphi = \frac{Tl}{GI_p}, \qquad G = \frac{E}{2(1 + \mu)} \approx 80\ \text{ГПа для стали}.$$

$GI_p$ **жёсткость при кручении**. Условие жёсткости обычно по погонному углу: $\theta = \varphi/l \le [\theta]$, для валов ~0.25–1 °/м.

### Момент от мощности

$$T = \frac{P}{\omega} = \frac{9550\,P[\text{кВт}]}{n[\text{об/мин}]}\ \text{Н·м}.$$

Двигатель 7.5 кВт на 1450 об/мин даёт ≈ 49 Н·м. После редуктора с $u = 20$ момент вырастет в ~20 раз (минус КПД), а обороты упадут во столько же.

### Почему валы делают полыми

Внутренние волокна почти не работают (там $\tau \to 0$). Труба с $c = 0.8$ весит на 64% меньше сплошного вала того же наружного диаметра, а теряет только 41% $W_p$. Поэтому карданные валы и валы самолётов полые.

**Проектный расчёт** вала на чистое кручение: $d \ge \sqrt[3]{\dfrac{16T}{\pi[\tau]}}$. Для предварительной оценки диаметра в деталях машин берут заниженное $[\tau] = 15\dots25$ МПа, чтобы учесть ещё не известный изгиб.

## Напряжённое состояние в точке

В точке тела на разных площадках разные напряжения. Всегда есть три взаимно перпендикулярные **главные площадки**, на которых $\tau = 0$, а нормальные напряжения $\sigma_1 \ge \sigma_2 \ge \sigma_3$ называются **главными** (это собственные числа тензора напряжений).

Плоское напряжённое состояние ($\sigma_x$, $\sigma_y$, $\tau_{xy}$):

$$\sigma_{\max,\min} = \frac{\sigma_x + \sigma_y}{2} \pm \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2}, \qquad \tan 2\alpha_0 = -\frac{2\tau_{xy}}{\sigma_x - \sigma_y}.$$

**Круг Мора**: центр $\left(\frac{\sigma_x + \sigma_y}{2}, 0\right)$, радиус $R = \tau_{\max}$. Точки круга дают напряжения на всех наклонных площадках, поворот площадки на $\alpha$ соответствует повороту по кругу на $2\alpha$.

**Закон парности касательных напряжений**: на двух перпендикулярных площадках $\tau$ равны по модулю.

## Теории прочности (критерии)

В опыте на растяжение предельное напряжение известно. А как быть при сложном состоянии? Вводят **эквивалентное напряжение** $\sigma_\text{экв}$, которое сравнивают с $[\sigma]$ от простого растяжения.

| Теория | $\sigma_\text{экв}$ | Для чего |
|---|---|---|
| I, наибольших нормальных напряжений | $\sigma_1$ | хрупкие материалы, исторически |
| III, наибольших касательных (Треска–Сен-Венан) | $\sigma_1 - \sigma_3$ | пластичные, с запасом |
| IV, энергетическая (Губер–Мизес–Хенки) | $\sqrt{\tfrac12[(\sigma_1-\sigma_2)^2 + (\sigma_2-\sigma_3)^2 + (\sigma_3-\sigma_1)^2]}$ | пластичные, точнее всего |
| Мора | $\sigma_1 - k\sigma_3$, $k = \sigma_\text{в.р}/\sigma_\text{в.с}$ | разно сопротивляющиеся (чугун) |

«Von Mises stress», который красит модель в ANSYS и SolidWorks, это и есть IV теория.

## Изгиб с кручением (расчёт валов)

В точке поверхности вала нормальное напряжение от изгиба $\sigma = M/W$ и касательное от кручения $\tau = T/W_p = T/(2W)$. Для такого состояния:

$$\sigma_\text{экв}^{III} = \sqrt{\sigma^2 + 4\tau^2} = \frac{\sqrt{M^2 + T^2}}{W},$$

$$\sigma_\text{экв}^{IV} = \sqrt{\sigma^2 + 3\tau^2} = \frac{\sqrt{M^2 + 0.75T^2}}{W}.$$

Если изгиб в двух плоскостях, сначала складываем геометрически: $M = \sqrt{M_x^2 + M_y^2}$.

Отсюда диаметр: $d \ge \sqrt[3]{\dfrac{32 M_\text{экв}}{\pi[\sigma]}}$.

```calc
P = 7.5 | 0.1..100 | кВт | Мощность
n = 1450 | 10..6000 | об/мин | Частота вращения
M = 60 | 0..2000 | Н·м | Изгибающий момент
d = 25 | 10..150 | мм | Диаметр вала
T = 9550*P/n | | Н·м | Крутящий момент
W = pi*d^3/32 | | мм³ | Осевой момент сопротивления
s = M*1000/W | | МПа | Напряжение изгиба
t = T*1000/(2*W) | | МПа | Напряжение кручения
seq = sqrt(s^2 + 3*t^2) | | МПа | Эквивалентное по Мизесу
```

## Карточки

```cards
Максимальное касательное напряжение при кручении :: $\tau = T/W_p$
Полярный момент сопротивления круга :: $W_p = \pi d^3/16 \approx 0.2d^3$
Угол закручивания :: $\varphi = Tl/(GI_p)$
Модуль сдвига :: $G = E/(2(1 + \mu))$, сталь ≈ 80 ГПа
Момент через мощность и обороты :: $T = 9550 P/n$ (кВт, об/мин → Н·м)
Эквивалентное напряжение по Треска :: $\sigma_1 - \sigma_3$
Эквивалентное напряжение изгиб + кручение по Мизесу :: $\sqrt{\sigma^2 + 3\tau^2}$
Эквивалентный момент по III теории :: $\sqrt{M^2 + T^2}$
Радиус круга Мора :: $\tau_{\max}$
Поворот площадки на $\alpha$ на круге Мора :: поворот на $2\alpha$
```
