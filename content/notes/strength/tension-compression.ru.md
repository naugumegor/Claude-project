## Метод сечений (РОЗУ)

Главный приём сопромата. Чтобы найти внутренние силы:

1. **Р**азрезаем стержень в интересующем месте.
2. **О**тбрасываем одну часть (обычно ту, где больше неизвестных, например заделку).
3. **З**аменяем действие отброшенной части внутренними силами.
4. **У**равновешиваем оставшуюся часть: из уравнений статики находим внутренние силы.

При растяжении-сжатии внутренняя сила одна: **продольная сила** $N$. Правило знаков: растяжение «+», сжатие «−». График $N$ по длине называют **эпюрой**.

## Напряжения

$$\sigma = \frac{N}{A}.$$

Единицы: $1\ \text{МПа} = 1\ \text{Н/мм}^2 = 10^6$ Па. Удобно считать силы в Н, площади в мм², сразу получаешь МПа.

## Деформации и закон Гука

Относительная продольная деформация $\varepsilon = \Delta l / l$. В упругой зоне:

$$\sigma = E\varepsilon, \qquad \Delta l = \frac{N l}{EA}.$$

$E$ **модуль упругости** (модуль Юнга): сталь ≈ 200–210 ГПа, алюминиевые сплавы ≈ 70 ГПа, медь ≈ 110 ГПа, титан ≈ 110 ГПа, бетон ≈ 30 ГПа. $EA$ называется **жёсткостью сечения** при растяжении.

Если $N$, $E$ или $A$ меняются по длине, удлинение считают по участкам и складывают, или интегралом $\Delta l = \int \frac{N\,dx}{EA}$.

**Коэффициент Пуассона** $\mu = -\varepsilon_\text{попер}/\varepsilon$: при растяжении стержень утончается. Сталь ≈ 0.3, резина ≈ 0.5 (несжимаема), пробка ≈ 0 (поэтому идеальна для бутылок).

**Температурные деформации**: $\Delta l_t = \alpha\,\Delta T\,l$. Для стали $\alpha \approx 12\cdot10^{-6}$ 1/°C. Если стержень зажат с двух сторон, возникают напряжения $\sigma = E\alpha\Delta T$: при нагреве на 50 °C это ≈ 120 МПа. Поэтому у рельсов и трубопроводов компенсаторы.

## Диаграмма растяжения малоуглеродистой стали

Характерные точки (для стали Ст3 примерно):

- **Предел пропорциональности** $\sigma_\text{пц}$: до него закон Гука строго выполняется.
- **Предел упругости** $\sigma_\text{у}$: до него после разгрузки нет остаточных деформаций.
- **Предел текучести** $\sigma_\text{т}$ (≈ 240 МПа): площадка текучести, металл «течёт» без роста нагрузки, на образце видны линии Чернова–Людерса. Для материалов без площадки берут **условный** предел $\sigma_{0.2}$ (остаточная деформация 0.2%).
- **Предел прочности (временное сопротивление)** $\sigma_\text{в}$ (≈ 380–460 МПа): максимум нагрузки, дальше образуется шейка.
- Разрыв.

Пластичность характеризуют **относительным удлинением** $\delta$ и **сужением** $\psi$ после разрыва. Хрупкие материалы (чугун, стекло) разрушаются без заметных пластических деформаций и плохо работают на растяжение, зато хорошо на сжатие.

## Расчёт на прочность

Условие прочности:

$$\sigma_{\max} = \frac{N_{\max}}{A} \le [\sigma], \qquad [\sigma] = \frac{\sigma_\text{пред}}{[n]}.$$

$\sigma_\text{пред}$ это $\sigma_\text{т}$ для пластичных и $\sigma_\text{в}$ для хрупких материалов. Коэффициент запаса $[n]$ обычно 1.5–2.5 по текучести и 2.5–5 по прочности.

### Три типа задач

1. **Проверочный расчёт**: известны $N$ и $A$, проверяем $\sigma \le [\sigma]$.
2. **Проектный расчёт**: подбираем сечение $A \ge N/[\sigma]$.
3. **Допускаемая нагрузка**: $[N] = [\sigma]A$.

### Пример

Стальная тяга, $N = 50$ кН, сталь 45 с $\sigma_\text{т} = 360$ МПа, $[n] = 2$. Тогда $[\sigma] = 180$ МПа и $A \ge 50000/180 = 278$ мм², то есть $d \ge \sqrt{4A/\pi} = 18.8$ мм. Берём $d = 20$ мм из нормального ряда.

```calc
N = 50 | 1..300 | кН | Продольная сила
d = 20 | 5..80 | мм | Диаметр тяги
sT = 360 | 200..1200 | МПа | Предел текучести
l = 1000 | 100..5000 | мм | Длина
A = pi*d^2/4 | | мм² | Площадь
s = N*1000/A | | МПа | Напряжение
n = sT/s | | | Запас по текучести
dl = N*1000*l/(200000*A) | | мм | Удлинение (E = 200 ГПа)
```

## Концентрация напряжений

Возле отверстий, выточек, галтелей напряжения выше номинальных: $\sigma_{\max} = K_t\sigma_\text{ном}$. Для маленького отверстия в широкой пластине $K_t = 3$. Для пластичных материалов при статике это не страшно (текучесть перераспределяет), для хрупких и при **переменных нагрузках (усталость)** очень опасно.
