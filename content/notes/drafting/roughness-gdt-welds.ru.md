## Шероховатость поверхности (ГОСТ 2.309, ISO 21920/1302)

Короткая версия всех таблиц отсюда, плюс посадки и марки сталей, есть на странице [Справочник](/ru/reference).

### Параметры

- **Ra**: среднее арифметическое отклонение профиля, мкм. Самый употребимый.
- **Rz**: высота неровностей профиля (по сути средняя высота пиков от впадин), мкм. Для грубых поверхностей. Ориентировочно $Rz \approx (4\dots7)Ra$.
- **Rmax**, **Sm**, **tp** для особых случаев (уплотнения, трущиеся пары).

Ряд предпочтительных Ra: 0.025; 0.05; 0.1; 0.2; 0.4; 0.8; 1.6; 3.2; 6.3; 12.5; 25; 50.

### Знаки

- **√** (галочка без полки): способ обработки не устанавливается.
- **√ с горизонтальной чертой** (треугольник замкнут сверху): поверхность образована **удалением материала** (точение, фрезерование, шлифование).
- **√ с кружком**: поверхность **без удаления материала** (литьё, ковка, прокат), или поверхность не обрабатывается по этому чертежу.

Значение пишется над знаком: «Ra 1.6». Знак стоит на линии контура, выносной линии или полке выноски, остриём к поверхности.

Одинаковая шероховатость для большинства поверхностей ставится **в правом верхнем углу** чертежа: «Ra 6.3 (√)». Знак в скобках означает «все остальные поверхности».

### Какую шероховатость даёт обработка

| Обработка | Ra, мкм |
|---|---|
| Литьё в песчаную форму, ковка | 25–100 |
| Черновое точение, фрезерование | 6.3–25 |
| Чистовое точение, фрезерование | 1.6–6.3 |
| Развёртывание, тонкое точение | 0.8–3.2 |
| Шлифование | 0.2–1.6 |
| Хонингование, полирование, доводка | 0.025–0.4 |

### Что куда назначать

| Поверхность | Ra |
|---|---|
| Свободные нерабочие поверхности | 6.3–12.5 |
| Торцы под буртики, привалочные плоскости | 3.2–6.3 |
| Посадочные под колёса (H7/k6) | 0.8–1.6 |
| Шейки под подшипники качения | 0.4–0.8 (отверстия корпуса 0.8–1.6) |
| Под манжетные уплотнения | 0.2–0.4 |
| Рабочие поверхности зубьев | 0.8–1.6 |

Логика: чем точнее квалитет, тем меньше Ra. Грубо $Ra \le 0.05\cdot IT$ для ответственных посадок.

## Базы и допуски формы и расположения (ГОСТ 2.308, ISO 1101)

### База

**База** это поверхность, ось или точка, от которой задаётся расположение. Обозначается **зачернённым треугольником**, соединённым с рамкой с буквой (А, Б, В…). Если треугольник на продолжении размерной линии, базой является **ось или плоскость симметрии** этого элемента, а не его поверхность.

### Рамка допуска

Прямоугольник из 2–5 ячеек: **знак** допуска | **значение** в мм | **база** (одна или несколько). Соединяется стрелкой с нормируемым элементом.

Пример: `⊥ | 0.02 | А` значит: допуск перпендикулярности 0.02 мм относительно базы А.

Если значение со знаком Ø (`⌖ | Ø0.1 | А | Б`), поле допуска цилиндрическое.

### Знаки

| Группа | Допуск | Знак |
|---|---|---|
| Форма | прямолинейности | — |
| | плоскостности | ▱ |
| | круглости | ○ |
| | цилиндричности | ⌭ |
| | профиля продольного сечения | = |
| Ориентация | параллельности | ∥ |
| | перпендикулярности | ⊥ |
| | наклона | ∠ |
| Расположение | соосности | ◎ |
| | симметричности | ⌯ |
| | позиционный | ⌖ |
| | пересечения осей | ✕ |
| Биение | радиального / торцового | ↗ |
| | полного | ⌰ |
| Суммарные | формы заданного профиля / поверхности | ⌒ / ⌓ |

### Типичные назначения на валу

- Шейки под подшипники: **цилиндричность** (≈ 1/4–1/3 допуска размера) и **радиальное биение** относительно общей оси шеек (база А–Б).
- Буртики под подшипники и колёса: **торцовое биение** относительно оси.
- Шпоночный паз: **симметричность** и **параллельность** относительно оси.
- Посадочная под колесо: радиальное биение или соосность относительно А–Б.

## Сварные швы на чертеже (ГОСТ 2.312 и ISO 2553)

### По ЕСКД

- Видимый шов: **сплошная основная** линия, невидимый: **штриховая**.
- Одиночная сварная точка: знак «+».
- От шва проводится **линия-выноска с односторонней стрелкой** и полкой.
- Условное обозначение на полке (лицевая сторона) или под полкой (оборотная). Состав: ГОСТ на тип шва (ГОСТ 5264 ручная дуговая, 14771 в защитных газах, 8713 под флюсом) → буквенно-цифровое обозначение шва (С стыковой, У угловой, Т тавровый, Н нахлёсточный + номер, например С17, Т1, У4, Н1) → способ сварки → знак ⊿ и катет → вспомогательные знаки.

Вспомогательные знаки: **○** шов по замкнутой линии, **⌐** (флажок) монтажный шов, **⌒** усиление снять, **~** наплывы и неровности обработать с плавным переходом, прерывистый шов «длина / шаг» (с «Z» для шахматного).

Пример: `ГОСТ 14771-76-Т3-УП-⊿6` = тавровое, угловой шов с двух сторон без скоса кромок, в углекислом газе плавящимся электродом, катет 6 мм.

### По ISO 2553 (для сравнения)

Стрелка + двойная **опорная линия** (сплошная + штриховая). Символ шва на сплошной линии = шов на стороне стрелки, на штриховой = с другой стороны. Символы: ◺ угловой, ‖ стыковой без разделки, V V-образная разделка и т.д. Размер углового шва: **a** (толщина, высота треугольника) или **z** (катет), например `a5 ◺ 200`. Флажок = монтажный шов, кружок = по контуру.

Главная ловушка при переходе ЕСКД ↔ ISO: в ЕСКД пишут **катет**, в ISO чаще **a** (= 0.7 катета).

## Карточки

```cards
Ra :: среднее арифметическое отклонение профиля, мкм
Знак шероховатости с кружком :: поверхность без удаления материала
Шероховатость шейки под подшипник :: Ra 0.4–0.8
Ra после чистового точения :: 1.6–6.3 мкм
Ra после шлифования :: 0.2–1.6 мкм
Как обозначают базу :: зачернённый треугольник + рамка с буквой
Треугольник базы на продолжении размерной линии :: базой является ось или плоскость симметрии
Знак ⊥ :: допуск перпендикулярности
Знак ◎ :: допуск соосности
Знак ↗ :: радиальное или торцовое биение
Обозначение ⊿6 в ЕСКД :: катет углового шва 6 мм
Размер «a5» в ISO 2553 :: толщина углового шва 5 мм (≈ 0.7 катета)
Флажок на выноске шва :: монтажный шов
```
