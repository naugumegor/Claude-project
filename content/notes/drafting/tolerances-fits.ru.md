## Зачем это всё

Деталь нельзя сделать точно в размер. Поэтому конструктор задаёт **границы**, в которые размер обязан попасть, а характер соединения двух деталей (свободно крутится, туго сидит, запрессовано) задаётся сочетанием этих границ. Система стандартизирована: **ISO 286** = ГОСТ 25346 / 25347.

## Термины

- **Номинальный размер**: размер, от которого отсчитывают отклонения (например Ø40).
- **Верхнее** и **нижнее отклонения**: ES, EI для отверстий, es, ei для валов. Пример: $\varnothing40^{+0.025}_{0}$.
- **Допуск** $T$ = наибольший предельный размер − наименьший = верхнее − нижнее отклонение. Всегда положительный.
- **Поле допуска**: зона между предельными размерами, обозначается буквой + цифрой: H7, g6.

## Квалитет (точность)

Цифра в поле допуска. **IT01…IT18**: чем больше число, тем грубее. Допуск зависит от квалитета и интервала размеров.

| Квалитет | Где |
|---|---|
| IT5–IT6 | точные валы под подшипники, шпиндели |
| IT7 | отверстия в ответственных соединениях (самое ходовое) |
| IT8–IT9 | менее ответственные посадки |
| IT11–IT12 | свободные размеры, грубые посадки |
| IT14 | **неуказанные допуски** (то, что на чертеже без отклонений) |

Для Ø30–50: IT6 = 16 мкм, IT7 = 25 мкм, IT8 = 39 мкм, IT9 = 62 мкм, IT11 = 160 мкм.

Ориентир по технологии: точение IT9–IT11 (чистовое до IT7–IT8), шлифование IT6–IT7, хонингование, доводка IT5 и точнее. Чем точнее, тем дороже, причём экспоненциально.

## Основные отклонения (буквы)

Буква показывает **положение поля допуска** относительно нулевой линии (номинала). **Большие буквы для отверстий, маленькие для валов.**

- **H** (отверстие): нижнее отклонение = 0, поле вверх. **h** (вал): верхнее = 0, поле вниз.
- Валы **a…g**: поле ниже нуля, вал меньше номинала → зазор с H.
- Валы **js, j, k, m, n**: поле около нуля → переходные посадки.
- Валы **p, r, s, t, u…z**: поле выше нуля, вал больше отверстия → натяг.

## Система отверстия

Почти всегда используют **систему отверстия**: отверстие H (обычно H7), а характер посадки меняют полем вала. Причина: отверстия обрабатывают мерным инструментом (развёртки, протяжки) и мерят калибрами, а вал легко точить и шлифовать на любой размер. **Система вала** (h) применяется, когда на гладкий калиброванный вал сажают разные детали, и для наружных колец подшипников и шпонок.

## Посадки

Наведи на обозначение посадки, всплывут предельные отклонения, зазоры и натяги. Все поля допусков собраны на странице [Справочник](/ru/reference).

Посадка записывается дробью: **Ø40 H7/g6** (или $\varnothing40\frac{H7}{g6}$).

### С зазором

$S_{\max} = ES - ei$, $S_{\min} = EI - es$.

| Посадка | Где |
|---|---|
| `H7/h6` | скользящая, точное центрирование с возможностью сборки руками: сменные шестерни, центрирующие пояски |
| `H7/g6` | движение с малым зазором: золотники, шпиндели делительных головок, плунжеры |
| `H7/f7` | ходовая: подшипники скольжения при умеренных скоростях |
| `H8/e8`, `H9/d9` | свободное вращение, большие скорости, температурные деформации |
| `H11/d11`, `H11/c11` | грубые свободные: крышки, шарниры сельхозмашин |

### Переходные

Может получиться и зазор, и натяг. Нужны для точного центрирования и разъёмных соединений с дополнительным креплением (шпонка, винт).

| Посадка | Где |
|---|---|
| `H7/js6` | легко собирается, частая разборка: шкивы, втулки |
| `H7/k6` | **напряжённая**, самая ходовая: зубчатые колёса и муфты на валах со шпонкой |
| `H7/m6` | тугая: колёса при ударных нагрузках |
| `H7/n6` | глухая: редко разбираемые, кондукторные втулки |

### С натягом

$N_{\max} = es - EI$, $N_{\min} = ei - ES$. Передают момент и силу без дополнительного крепления (или с ним для надёжности).

| Посадка | Где |
|---|---|
| `H7/p6` | лёгкий прессовый: втулки в корпусе, колёса с шпонкой при больших нагрузках |
| `H7/r6` | средний: венцы червячных колёс, колёса на валах |
| `H7/s6` | прессовый: втулки подшипников скольжения, кольца |
| `H7/u7`, `H8/u8` | тяжёлый: без шпонок, сборка с нагревом |

### Пример расчёта: Ø40 H7/p6

Отверстие H7: $\varnothing40^{+0.025}_{0}$. Вал p6: $\varnothing40^{+0.042}_{+0.026}$.

$N_{\max} = 0.042 - 0 = 0.042$ мм, $N_{\min} = 0.026 - 0.025 = 0.001$ мм. Натяг всегда, хотя минимальный крошечный. Посадка с гарантированным натягом.

## Подшипники качения

Кольца подшипника изготовлены со своими полями (L0 для внутреннего, l0 для наружного), поэтому на чертеже указывают только поле **вала и корпуса**:
- вращающееся внутреннее кольцо (циркуляционное нагружение): вал **k6**, **js6**, при больших нагрузках **m6**;
- неподвижное наружное кольцо (местное нагружение): корпус **H7** (может проворачиваться, это даже полезно для равномерного износа).

## Как это пишут на чертеже

- Детальный: $\varnothing40H7$, $\varnothing40^{+0.025}$, или $\varnothing40H7(^{+0.025})$.
- Сборочный: Ø40 H7/k6.
- Неуказанные допуски в технических требованиях: «Неуказанные предельные отклонения размеров: H14, h14, ±IT14/2» (или по ГОСТ 30893.1 класс m).

## Карточки

```cards
Допуск :: разность наибольшего и наименьшего предельных размеров
Квалитет :: степень точности, IT01…IT18, больше = грубее
Отверстие H :: нижнее отклонение равно нулю
Вал h :: верхнее отклонение равно нулю
Почему система отверстия :: отверстия делают мерным инструментом и мерят калибрами
Посадка H7/g6 :: с малым зазором, точное перемещение
Посадка H7/k6 :: переходная, колёса на валу со шпонкой
Посадка H7/p6 :: лёгкая прессовая, с натягом
Посадка H7/h6 :: скользящая, наименьший зазор = 0
Внутреннее кольцо подшипника на вал :: k6 или js6
Наружное кольцо подшипника в корпус :: H7
IT7 для Ø30–50 :: 25 мкм
Неуказанные допуски обычно :: IT14
```
