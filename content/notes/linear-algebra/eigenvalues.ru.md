## Определение

Ненулевой вектор $\vec v$ называется **собственным** для матрицы $A$, если преобразование только растягивает его, не поворачивая:

$$A\vec v = \lambda \vec v.$$

Число $\lambda$ это **собственное число** (во сколько раз растянулось).

## Как искать

Переписываем как $(A - \lambda E)\vec v = 0$. Ненулевое решение есть только если матрица вырождена:

$$\det(A - \lambda E) = 0 \quad \text{(характеристическое уравнение)}.$$

1. Решаем характеристическое уравнение, получаем $\lambda_1, \lambda_2, \dots$
2. Для каждого $\lambda_i$ решаем $(A - \lambda_i E)\vec v = 0$ методом Гаусса.

### Пример

$A = \begin{pmatrix}4 & 1\\ 2 & 3\end{pmatrix}$. Характеристическое уравнение: $(4-\lambda)(3-\lambda) - 2 = \lambda^2 - 7\lambda + 10 = 0$, откуда $\lambda_1 = 5$, $\lambda_2 = 2$.

Для $\lambda = 5$: $-v_1 + v_2 = 0 \Rightarrow \vec v_1 = (1, 1)$. Для $\lambda = 2$: $2v_1 + v_2 = 0 \Rightarrow \vec v_2 = (1, -2)$.

Проверки: $\lambda_1 + \lambda_2 = \operatorname{tr} A = 7$ (сумма диагонали), $\lambda_1\lambda_2 = \det A = 10$.

## Симметричные матрицы (самое важное для инженера)

Если $A = A^T$, то:
- все собственные числа **вещественные**;
- собственные векторы для разных $\lambda$ **ортогональны**;
- матрицу можно привести к диагональному виду поворотом системы координат.

А симметричных матриц в механике полно.

## Применения

### Главные напряжения

Тензор напряжений $\sigma$ симметричный. Его собственные числа это **главные напряжения** $\sigma_1 \ge \sigma_2 \ge \sigma_3$, а собственные векторы это **главные площадки**, на которых касательных напряжений нет. Для плоского случая:

$$\sigma_{1,2} = \frac{\sigma_x + \sigma_y}{2} \pm \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2}.$$

Это и есть решение характеристического уравнения $2\times2$. Круг Мора это его графическая версия.

### Главные оси инерции

Тензор инерции тела (или моменты инерции сечения $I_x$, $I_y$, $I_{xy}$) диагонализуется так же. Собственные векторы дают **главные оси**, вокруг которых тело вращается без «биения».

### Собственные частоты колебаний

Система масс и пружин: $M\ddot{\vec x} + K\vec x = 0$. Ищем решение $\vec x = \vec v\sin\omega t$ и получаем **обобщённую задачу на собственные значения**:

$$(K - \omega^2 M)\vec v = 0, \qquad \det(K - \omega^2 M) = 0.$$

Собственные числа дают **собственные частоты** $\omega_i$, а векторы это **формы колебаний** (моды). Модальный анализ в ANSYS/SolidWorks Simulation делает ровно это. Если рабочая частота машины близка к $\omega_i$, будет резонанс.

### Устойчивость

Для линейной системы $\dot{\vec x} = A\vec x$ решение затухает, если у всех собственных чисел $\operatorname{Re}\lambda < 0$. В сопромате критическая сила Эйлера тоже находится как собственное число.

```python
import numpy as np

# Главные напряжения для плоского состояния, МПа
sx, sy, txy = 80, -20, 40
S = np.array([[sx, txy], [txy, sy]])
vals, vecs = np.linalg.eigh(S)
print("главные напряжения:", vals[::-1])
v1 = vecs[:, 1]  # вектор для наибольшего σ
print("угол главной площадки, °:", np.degrees(np.arctan(v1[1] / v1[0])))
print("по формуле tg2α = 2τ/(σx − σy):", 0.5 * np.degrees(np.arctan2(2 * txy, sx - sy)))
```
