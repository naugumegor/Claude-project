## Спрос

**Закон спроса**: при прочих равных чем выше цена, тем меньше покупают. Кривая спроса идёт вниз. В учебных задачах её берут прямой; экономисты по традиции рисуют цену по вертикали:

$$P = a - bQ.$$

Движение **вдоль** кривой вызывает только цена. Кривую **сдвигают** другие факторы: доходы покупателей, цены заменителей и дополняющих товаров, мода, ожидания, число покупателей.

## Предложение

Чем выше цена, тем больше продавцы готовы произвести (выгоднее, могут включиться менее эффективные производители):

$$P = c + dQ.$$

Сдвигают кривую предложения: цены сырья и труда, технологии, налоги и субсидии, число фирм.

## Равновесие

Там, где кривые пересекаются: $a - bQ = c + dQ$, откуда

$$Q^* = \frac{a - c}{b + d}, \qquad P^* = a - bQ^*.$$

Если цена выше равновесной, возникает **излишек** товара, продавцы снижают цены. Если ниже, **дефицит** и очереди, цена растёт.

Пример: $P = 100 - 2Q$, $P = 10 + Q$. Тогда $Q^* = 90/3 = 30$, $P^* = 40$.

## Излишки

**Излишек потребителя** это сколько покупатели готовы были заплатить сверх фактической цены (треугольник под спросом и над ценой):

$$CS = \tfrac12(a - P^*)Q^* = \tfrac12\cdot60\cdot30 = 900.$$

**Излишек производителя**: $PS = \tfrac12(P^* - c)Q^* = \tfrac12\cdot30\cdot30 = 450$.

Сумма излишков это общественное благосостояние. На конкурентном рынке без внешних эффектов оно максимально.

## Налог и кто его на самом деле платит

Налог $t$ на каждую единицу, который платит продавец, сдвигает предложение вверх: $P = c + t + dQ$.

При $t = 15$: $Q = (90 - 15)/3 = 25$, покупатель платит $P_\text{пок} = 100 - 50 = 50$, продавец получает $P_\text{пр} = 35$.

- Покупатели переплачивают $50 - 40 = 10$, продавцы недополучают $40 - 35 = 5$. **Кто формально платит налог, неважно**: распределение зависит от наклонов. Доля покупателя $= \dfrac{b}{b + d} = \dfrac23$.
- Сбор государства: $15\cdot25 = 375$.
- **Чистые потери** (deadweight loss), сделки, которые не состоялись: $\tfrac12\cdot15\cdot(30 - 25) = 37.5$.

Правило: налог ложится сильнее на ту сторону, которая **менее эластична**, то есть которой некуда деться (бензин, сигареты, лекарства).

## Потолок и пол цены

**Потолок** ниже равновесия (заморозка цен, аренда) создаёт **дефицит**: $Q_d > Q_s$, очереди, чёрный рынок, падение качества. **Пол** выше равновесия (минимальная цена, МРОТ) создаёт **излишек**: нераспроданный товар или безработица среди низкоквалифицированных.

## Эластичность

**Ценовая эластичность спроса** показывает, на сколько процентов изменится объём при изменении цены на 1%:

$$E_d = \frac{\Delta Q/Q}{\Delta P/P} = \frac{dQ}{dP}\cdot\frac{P}{Q}.$$

Обычно отрицательна, сравнивают по модулю:
- $|E| > 1$, **эластичный** спрос: рестораны, конкретная марка кофе, авиабилеты на отдых.
- $|E| < 1$, **неэластичный**: соль, бензин, инсулин, коммуналка.
- $|E| = 1$: единичная.

Для прямой $P = a - bQ$ эластичность **меняется вдоль кривой**: $E = -\dfrac{P}{a - P}$. В нашем примере при $P = 40$: $E = -40/60 \approx -0.67$.

**Дуговая** эластичность по двум точкам (формула средней точки):

$$E = \frac{(Q_2 - Q_1)/\bar Q}{(P_2 - P_1)/\bar P}.$$

### Эластичность и выручка

Выручка $TR = PQ$.
- Спрос **неэластичен**: подними цену, выручка вырастет.
- Спрос **эластичен**: снизь цену, выручка вырастет.
- Максимум выручки при $|E| = 1$, для прямой это $P = a/2$.

Отсюда практика: на неэластичные товары не делают скидок, на эластичные делают акции.

### Другие эластичности

- **Перекрёстная** $E_{xy} = \dfrac{\%\Delta Q_x}{\%\Delta P_y}$: $> 0$ заменители (чай и кофе), $< 0$ дополняющие (принтер и картриджи).
- **По доходу** $E_I = \dfrac{\%\Delta Q}{\%\Delta I}$: $> 1$ товары роскоши, $0..1$ необходимые, $< 0$ «низшие» (лапша быстрого приготовления).
- **Эластичность предложения** выше в длинном периоде: заводу нужно время, чтобы нарастить мощность.

## Карточки

```cards
Равновесие :: $Q^* = (a - c)/(b + d)$
Излишек потребителя :: площадь под спросом и над ценой
Кто платит налог :: менее эластичная сторона рынка
Чистые потери от налога :: $\tfrac12\,t\,\Delta Q$
Ценовая эластичность :: $\frac{dQ}{dP}\frac{P}{Q}$
Неэластичный спрос и выручка :: рост цены увеличивает выручку
Перекрёстная эластичность больше 0 :: товары-заменители
Потолок цены ниже равновесия :: дефицит
```

## Проверь себя

```quiz
? Цена кофе выросла на 10%, продажи упали на 25%. Эластичность?
+ −2.5, спрос эластичен
- −0.4, неэластичен
- −25
> $-25\%/10\% = -2.5$, по модулю больше 1. Поднимать цену было ошибкой: выручка упала.

? Правительство ввело налог на продавцов сигарет. Кто заплатит большую часть?
+ курильщики
- производители
- поровну
> Спрос на сигареты неэластичен, покупателям некуда деться.

? Что сдвинет кривую спроса на электромобили вправо?
- снижение цены электромобиля
+ рост цен на бензин
- рост цены лития
> Цена самого товара двигает вдоль кривой; бензин это цена заменителя. Литий двигает предложение.
```
