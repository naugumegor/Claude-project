## Издержки

- $TC = FC + VC(Q)$: общие = постоянные + переменные.
- Средние: $AC = TC/Q$, $AVC = VC/Q$, $AFC = FC/Q$ (всегда падает).
- **Предельные**: $MC = \dfrac{dTC}{dQ}$, сколько стоит **ещё одна** единица.

Кривая $MC$ пересекает $AVC$ и $AC$ **в их минимумах**. Это чистая математика: если следующая единица дешевле среднего, она тянет среднее вниз, если дороже, вверх.

U-образная форма $AC$ объясняется так: сначала постоянные затраты размазываются на большой объём (эффект масштаба), потом начинает работать **закон убывающей отдачи**: в тот же цех ставят всё больше людей, и каждый следующий даёт меньше.

**Экономические** издержки включают альтернативные: если ты вкладываешь свои 5 млн и своё время, их «зарплата» и «процент» тоже издержки. Поэтому нулевая экономическая прибыль это нормально: она означает, что ты зарабатываешь как в лучшей альтернативе.

```python
import numpy as np
import matplotlib.pyplot as plt

FC = 100
Q = np.linspace(0.5, 15, 300)
VC = 10*Q - Q**2 + 0.1*Q**3
MC = 10 - 2*Q + 0.3*Q**2
AVC = VC/Q
AC = (FC + VC)/Q

i = np.argmin(AC)
print(f"min AVC = {AVC.min():.2f} при Q = {Q[np.argmin(AVC)]:.1f}")
print(f"min AC  = {AC[i]:.2f} при Q = {Q[i]:.1f}, MC там = {MC[i]:.2f}")

plt.plot(Q, MC, label="MC")
plt.plot(Q, AVC, label="AVC")
plt.plot(Q, AC, label="AC")
plt.ylim(0, 60); plt.xlabel("Q"); plt.ylabel("₽ за единицу"); plt.legend(); plt.grid(alpha=.3)
plt.show()
```

## Главное правило: MR = MC

Прибыль $\Pi(Q) = TR(Q) - TC(Q)$ максимальна, где производная равна нулю:

$$MR = MC,$$

где $MR = dTR/dQ$ это **предельная выручка**. Пока следующая единица приносит больше, чем стоит, её надо производить.

## Совершенная конкуренция

Много мелких фирм, одинаковый товар, свободный вход. Фирма не влияет на цену, поэтому $MR = P$, и правило превращается в $P = MC$.

- **Краткосрочно**: если $P < \min AVC$, производство надо **остановить**: каждая единица не покрывает даже переменных затрат. Если $\min AVC < P < \min AC$, работаем в убыток, но так теряем меньше, чем при простое (постоянные затраты всё равно платить).
- **Долгосрочно**: прибыль привлекает новые фирмы, цена падает до $P = \min AC$, экономическая прибыль ноль.

## Монополия

Одна фирма, нет заменителей, высокие барьеры входа. Монополист сам выбирает цену, но двигается по кривой спроса. Для $P = a - bQ$:

$$TR = aQ - bQ^2, \qquad MR = a - 2bQ.$$

Пример: $P = 100 - 2Q$, $MC = 20$.
- Монополия: $100 - 4Q = 20 \Rightarrow Q = 20$, $P = 60$.
- Конкурентный рынок: $P = MC = 20 \Rightarrow Q = 40$.
- Монополия продаёт **вдвое меньше** и **втрое дороже**. Чистые потери общества $\tfrac12(60 - 20)(40 - 20) = 400$.

**Индекс Лернера** (рыночная власть):

$$L = \frac{P - MC}{P} = \frac{1}{|E_d|}.$$

В примере $L = 40/60 = 2/3$, и правда эластичность в точке $|E| = 60/(2\cdot20) = 1.5$. Вывод: монополист никогда не работает на неэластичном участке спроса.

## Монополистическая конкуренция

Много фирм, но товары **различаются**: кафе, барбершопы, бренды одежды. Каждая фирма немного монополист своего продукта (кривая спроса наклонная), но вход свободный, поэтому в долгосрочном периоде прибыль стремится к нулю. Конкурируют брендом, сервисом, локацией, а не только ценой.

## Олигополия

Несколько крупных фирм (сотовые операторы, авиастроение, металлургия). Ключевая черта: **стратегическое взаимодействие**, каждая учитывает ответ конкурентов.

**Дилемма заключённого** про две фирмы, выбирающие цену (прибыль в млн, первая цифра фирмы А):

| | Б: высокая цена | Б: низкая цена |
|---|---|---|
| **А: высокая** | 10, 10 | 2, 14 |
| **А: низкая** | 14, 2 | 5, 5 |

Каждой выгодно снизить цену при любом выборе соперника, поэтому равновесие (Нэша) это «низкая, низкая» с прибылью 5 и 5, хотя вместе они могли бы получать по 10. Отсюда желание картельного сговора (незаконно) и ценовые войны. В повторяющейся игре стратегия «око за око» поддерживает высокие цены без явного сговора.

## Карточки

```cards
Предельные издержки :: $MC = dTC/dQ$
Правило максимизации прибыли :: $MR = MC$
Когда закрывать производство в краткосрочном периоде :: $P < \min AVC$
Где MC пересекает AC :: в минимуме AC
Предельная выручка при линейном спросе :: $MR = a - 2bQ$
Индекс Лернера :: $(P - MC)/P = 1/|E|$

```
