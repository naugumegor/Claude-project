## Основная теорема зацепления

Чтобы передаточное отношение было **постоянным**, общая нормаль к профилям в точке контакта должна всегда проходить через одну и ту же точку на линии центров, **полюс зацепления** $P$. Профили, удовлетворяющие этому, называются **сопряжёнными**.

На практике почти всегда используют **эвольвентный** профиль (Эйлер). Эвольвента это кривая, которую описывает точка нити, сматываемой с **основной окружности**.

Почему эвольвента:
- линия зацепления прямая, сила давления направлена вдоль неё постоянно;
- передаточное отношение не зависит от точного межосевого расстояния (передача **нечувствительна** к погрешностям монтажа);
- все колёса одного модуля нарезаются одним инструментом (рейкой) методом обката.

## Основные параметры

- **Модуль** $m$ (мм): $m = p/\pi$, где $p$ шаг по делительной окружности. Стандартизирован (ГОСТ 9563): 1; 1.25; 1.5; 2; 2.5; 3; 4; 5; 6; 8; 10… Первый ряд предпочтительнее второго.
- **Число зубьев** $z$.
- **Угол профиля** (зацепления) исходного контура $\alpha = 20°$.

| Размер | Формула (прямозубое, без смещения) |
|---|---|
| Делительный диаметр | $d = mz$ |
| Диаметр вершин | $d_a = d + 2m = m(z + 2)$ |
| Диаметр впадин | $d_f = d - 2.5m = m(z - 2.5)$ |
| Основной диаметр | $d_b = d\cos\alpha$ |
| Высота зуба | $h = 2.25m$ |
| Межосевое расстояние | $a_w = m(z_1 + z_2)/2$ |

Для **косозубых** колёс с углом наклона $\beta$ вводят нормальный модуль $m_n$ (стандартный) и торцовый $m_t = m_n/\cos\beta$: $d = m_n z/\cos\beta$. Косой зуб входит в зацепление постепенно: тише и плавнее, но появляется **осевая сила** $F_a = F_t\tan\beta$. Шевронные колёса гасят её симметрией.

## Подрезание и смещение

При нарезании рейкой колесо с малым числом зубьев получает **подрезанную ножку** (ослабленный зуб). Минимальное число зубьев без подрезания при $\alpha = 20°$: $z_{\min} = 17$.

Лечится **смещением** исходного контура: инструмент отодвигают на $xm$ ($x$ коэффициент смещения). Положительное смещение утолщает ножку, позволяет $z < 17$, вписывает передачу в нестандартное межосевое расстояние и повышает прочность.

## Коэффициент перекрытия

$\varepsilon_\alpha$ показывает, сколько пар зубьев в среднем одновременно в зацеплении. Должен быть $\ge 1.1$–1.2 (иначе удары при пересменке). Для прямозубых обычно 1.4–1.8. Для косозубых добавляется осевое перекрытие $\varepsilon_\beta$, поэтому они плавнее.

## Передаточное отношение

Для пары колёс:

$$u = \frac{\omega_1}{\omega_2} = \frac{n_1}{n_2} = \frac{z_2}{z_1}.$$

Внешнее зацепление меняет направление вращения (знак «−»), внутреннее нет.

**Многоступенчатая** передача: $u_\text{общ} = u_1\cdot u_2\cdot u_3\cdots$. Момент растёт, обороты падают: $T_2 = T_1 u\eta$.

Рекомендуемые $u$ на одну ступень: цилиндрическая 2–6.3, коническая 1–4, червячная 8–80.

## Планетарные передачи

Есть звенья с подвижными осями (**сателлиты**), установленные на **водиле** $H$. Центральные колёса: солнечное $a$ и коронное (с внутренними зубьями) $b$.

**Формула Виллиса** (метод остановки водила): переходим в систему, вращающуюся с водилом, там все оси неподвижны:

$$\frac{\omega_a - \omega_H}{\omega_b - \omega_H} = u_{ab}^{(H)} = -\frac{z_b}{z_a}.$$

Самая популярная схема (Джеймса): корона $b$ неподвижна ($\omega_b = 0$), вход на солнце, выход с водила:

$$u_{aH} = 1 + \frac{z_b}{z_a}.$$

При $z_a = 20$, $z_b = 70$: $u = 4.5$.

**Условия сборки**: соосности ($z_b = z_a + 2z_g$ для сателлита $z_g$), соседства (сателлиты не задевают друг друга) и сборки ($(z_a + z_b)/k$ целое для $k$ сателлитов).

Плюсы: компактность, соосность входа и выхода, нагрузка делится между сателлитами. Применение: АКПП, редукторы мотор-колёс, вертолётные редукторы, дифференциал автомобиля (это тоже планетарный механизм с $W = 2$).

```calc
za = 20 | 12..60 | | Зубья солнца
zb = 70 | 40..200 | | Зубья короны
m = 2 | 1..10 | мм | Модуль
k = 3 | 2..6 | | Число сателлитов
zg = (zb - za)/2 | | | Зубья сателлита (из соосности)
u = 1 + zb/za | | | Передаточное отношение (корона стоит)
asm = (za + zb)/k | | | Условие сборки: должно быть целым
aw = m*(za + zg)/2 | | мм | Межосевое солнце–сателлит
```
