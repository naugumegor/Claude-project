## Частные производные

У функции $f(x, y)$ производную берут **по одной переменной, считая остальные константами**:

$$\frac{\partial f}{\partial x} = \lim_{h\to0}\frac{f(x+h, y) - f(x, y)}{h}.$$

Пример: $f = x^2 y + \sin y$. Тогда $f_x = 2xy$, $f_y = x^2 + \cos y$.

Смешанные производные гладкой функции не зависят от порядка: $f_{xy} = f_{yx}$ (теорема Шварца).

## Полный дифференциал и погрешности

$$df = \frac{\partial f}{\partial x}dx + \frac{\partial f}{\partial y}dy.$$

Это главная формула для **оценки погрешности косвенных измерений**. Например, напряжение $\sigma = F/A$: $\dfrac{\Delta\sigma}{\sigma} \approx \dfrac{\Delta F}{F} + \dfrac{\Delta A}{A}$.

## Градиент

$$\nabla f = \left(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}\right).$$

- Градиент показывает **направление наибыстрейшего роста** функции, а его длина это скорость роста.
- Градиент **перпендикулярен линиям (поверхностям) уровня**.
- Производная по направлению единичного вектора $\vec l$: $\dfrac{\partial f}{\partial l} = \nabla f \cdot \vec l$.

Где встречается: тепловой поток $\vec q = -\lambda\nabla T$ (закон Фурье), сила из потенциала $\vec F = -\nabla U$, градиентный спуск в оптимизации и машинном обучении.

## Экстремумы

1. **Необходимое условие**: $f_x = 0$, $f_y = 0$ (стационарная точка).
2. **Достаточное условие**: считаем $A = f_{xx}$, $B = f_{xy}$, $C = f_{yy}$, $\Delta = AC - B^2$.
   - $\Delta > 0$, $A > 0$: минимум;
   - $\Delta > 0$, $A < 0$: максимум;
   - $\Delta < 0$: седло, экстремума нет;
   - $\Delta = 0$: нужно копать глубже.

## Условный экстремум: метод Лагранжа

Найти экстремум $f(x, y)$ при условии $g(x, y) = 0$. Строим **функцию Лагранжа** $L = f - \lambda g$ и решаем $L_x = 0$, $L_y = 0$, $g = 0$.

### Пример: самая прочная балка из бревна

Из круглого бревна диаметром $d$ вырезаем прямоугольную балку $b\times h$. Момент сопротивления $W = bh^2/6$ надо максимизировать при $b^2 + h^2 = d^2$.

$L = bh^2 - \lambda(b^2 + h^2 - d^2)$, $L_b = h^2 - 2\lambda b = 0$, $L_h = 2bh - 2\lambda h = 0 \Rightarrow \lambda = b$, $h^2 = 2b^2$.

Ответ: $h/b = \sqrt2$, то есть $b = d/\sqrt3$, $h = d\sqrt{2/3}$. Это классический результат, который знали ещё плотники.

## Двойные и тройные интегралы

$$\iint_D f(x, y)\,dA, \qquad \iiint_V f\,dV.$$

Считаются как повторные: сначала по одной переменной при фиксированной другой. Для круглых областей переходи в **полярные координаты**: $x = r\cos\varphi$, $y = r\sin\varphi$, $dA = r\,dr\,d\varphi$ (не забывай якобиан $r$!).

Пример: полярный момент инерции круга радиуса $R$:

$$I_p = \iint r^2\,dA = \int_0^{2\pi}\!\!\int_0^R r^3\,dr\,d\varphi = \frac{\pi R^4}{2} = \frac{\pi d^4}{32}.$$

Эта формула потом всплывёт в кручении валов.
