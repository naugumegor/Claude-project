## Идея в одном предложении

**Определённый интеграл** это предел суммы огромного числа маленьких вкладов: режем область на кусочки $\Delta x$, на каждом считаем $f(x_i)\Delta x$ и складываем.

$$\int_a^b f(x)\,dx = \lim_{\max \Delta x_i \to 0}\ \sum_i f(\xi_i)\,\Delta x_i.$$

Если $f$ это высота, получаем площадь. Если $f$ это сила, получаем работу. Если $f$ это расход, получаем объём. Смысл всегда один: **накопление**.

## Формула Ньютона–Лейбница

Если $F' = f$ (то есть $F$ это первообразная), то

$$\int_a^b f(x)\,dx = F(b) - F(a).$$

Это мост между производной и интегралом: интегрирование это обратная операция к дифференцированию.

## Основные приёмы

- **Табличные интегралы**: $\int x^n dx = \dfrac{x^{n+1}}{n+1} + C$ ($n \ne -1$), $\int \dfrac{dx}{x} = \ln|x| + C$, $\int e^x dx = e^x + C$, $\int \cos x\,dx = \sin x + C$.
- **Замена переменной**: $\int f(g(x))\,g'(x)\,dx = \int f(u)\,du$, где $u = g(x)$.
- **По частям**: $\int u\,dv = uv - \int v\,du$. Выбирай $u$ то, что упрощается при дифференцировании (многочлен, логарифм, арктангенс).
- **Рациональные дроби**: раскладывай на простейшие.

## Инженерные применения

| Что считаем | Формула |
|---|---|
| Площадь под кривой | $A = \int_a^b y\,dx$ |
| Работа переменной силы | $W = \int_{x_1}^{x_2} F(x)\,dx$ |
| Работа газа | $W = \int_{V_1}^{V_2} p\,dV$ |
| Статический момент площади | $S_y = \int_A x\,dA$ |
| Координата центра тяжести | $x_c = S_y / A$ |
| Момент инерции сечения | $I_x = \int_A y^2\,dA$ |
| Длина кривой | $L = \int_a^b \sqrt{1 + y'^2}\,dx$ |

### Пример: момент инерции прямоугольника

Сечение $b \times h$, ось $x$ через центр. Полоска толщиной $dy$ на расстоянии $y$ имеет площадь $dA = b\,dy$:

$$I_x = \int_{-h/2}^{h/2} y^2\, b\, dy = b\left[\frac{y^3}{3}\right]_{-h/2}^{h/2} = \frac{b h^3}{12}.$$

Вот почему балку ставят «на ребро»: высота входит в куб, ширина в первой степени.

### Пример: работа при изотермическом сжатии

$pV = \text{const} = p_1 V_1$, значит $p = p_1V_1/V$ и

$$W = \int_{V_1}^{V_2} \frac{p_1 V_1}{V}\,dV = p_1 V_1 \ln\frac{V_2}{V_1}.$$

## Численное интегрирование

Когда первообразную не найти (или данные из эксперимента), используют:

- **метод трапеций**: $\int_a^b f\,dx \approx h\left(\frac{f_0 + f_n}{2} + f_1 + \dots + f_{n-1}\right)$, ошибка $\sim h^2$;
- **метод Симпсона** (парабола через три точки), ошибка $\sim h^4$.

```python
import numpy as np
from scipy.integrate import quad, trapezoid

# Момент инерции прямоугольника 40x120 мм численно
b, h = 40, 120
y = np.linspace(-h/2, h/2, 201)
print("трапеции:", trapezoid(b * y**2, y))
print("точно:   ", b * h**3 / 12)
print("quad:    ", quad(lambda t: b * t**2, -h/2, h/2)[0])
```
