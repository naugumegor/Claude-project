## Главное уравнение механики колебаний

Масса $m$ на пружине жёсткостью $c$ с демпфером $b$ под действием силы $F(t)$:

$$m\ddot x + b\dot x + c x = F(t).$$

Делим на $m$ и вводим обозначения: **собственная частота** $\omega_0 = \sqrt{c/m}$ и **коэффициент демпфирования** $\zeta = \dfrac{b}{2\sqrt{cm}}$:

$$\ddot x + 2\zeta\omega_0\dot x + \omega_0^2 x = F(t)/m.$$

## Однородное уравнение: характеристические корни

Для $a y'' + b y' + c y = 0$ ищем решение в виде $e^{rx}$ и получаем **характеристическое уравнение** $ar^2 + br + c = 0$.

| Корни | Общее решение | В механике |
|---|---|---|
| Два вещественных $r_1 \ne r_2$ | $C_1 e^{r_1 x} + C_2 e^{r_2 x}$ | $\zeta > 1$, передемпфирование, ползёт без колебаний |
| Кратный $r$ | $(C_1 + C_2 x)e^{rx}$ | $\zeta = 1$, критическое демпфирование, самый быстрый возврат без перелёта |
| Комплексные $\alpha \pm i\beta$ | $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$ | $\zeta < 1$, затухающие колебания |

При $\zeta < 1$ частота затухающих колебаний $\omega_d = \omega_0\sqrt{1 - \zeta^2}$, амплитуда падает как $e^{-\zeta\omega_0 t}$.

Логарифмический декремент (меряется по осциллограмме): $\delta = \ln\dfrac{A_n}{A_{n+1}} \approx 2\pi\zeta$.

## Неоднородное уравнение

Общее решение = общее решение однородного + **частное решение** неоднородного.

Частное ищут **методом подбора** по виду правой части:
- многочлен → многочлен той же степени;
- $e^{kx}$ → $Ae^{kx}$ (если $k$ корень характеристического, домножь на $x$);
- $\sin\omega x$, $\cos\omega x$ → $A\cos\omega x + B\sin\omega x$ (если $i\omega$ корень, домножь на $x$: это и есть математика резонанса).

Универсальный, но громоздкий путь: **вариация постоянных** (метод Лагранжа).

## Вынужденные колебания и резонанс

При $F = F_0\sin\omega t$ установившаяся амплитуда:

$$X = \frac{F_0/c}{\sqrt{(1 - \eta^2)^2 + (2\zeta\eta)^2}}, \qquad \eta = \frac{\omega}{\omega_0}.$$

Отношение $X/(F_0/c)$ называется **коэффициентом динамичности** $\mu$: во сколько раз динамическое перемещение больше статического.

- $\eta \ll 1$: $\mu \approx 1$, система «отслеживает» силу как в статике.
- $\eta \approx 1$: **резонанс**, $\mu_{\max} \approx \dfrac{1}{2\zeta}$. При $\zeta = 0.02$ (сталь) амплитуда в 25 раз больше статической.
- $\eta \gg 1$: $\mu \to 0$, масса не успевает реагировать. На этом работает **виброизоляция**: собственную частоту опор делают в 3–4 раза ниже рабочей.

```calc
m = 50 | 1..500 | кг | Масса
c = 200000 | 10000..2000000 | Н/м | Жёсткость
z = 0.05 | 0.005..1 | | Демпфирование ζ
w0 = sqrt(c/m) | | рад/с | Собственная частота
f0 = w0/(2*pi) | | Гц | Собственная частота
plot e: 0..3 | 1/sqrt((1 - e^2)^2 + (2*z*e)^2) | μ(η)
axes: η = ω/ω₀ ; μ
```

## Карточки

```cards
Собственная частота массы на пружине :: $\omega_0 = \sqrt{c/m}$
Коэффициент демпфирования :: $\zeta = b / (2\sqrt{cm})$
Критическое демпфирование :: $\zeta = 1$
Частота затухающих колебаний :: $\omega_d = \omega_0\sqrt{1 - \zeta^2}$
Пик коэффициента динамичности :: $\approx 1/(2\zeta)$
Условие виброизоляции :: $\omega / \omega_0 > \sqrt2$, на практике 3–4
Решение при комплексных корнях $\alpha \pm i\beta$ :: $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$
```
