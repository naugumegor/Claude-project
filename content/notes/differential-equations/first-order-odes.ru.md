## Что такое ОДУ

**Обыкновенное дифференциальное уравнение** связывает функцию $y(x)$ и её производные. Порядок уравнения это порядок старшей производной. Решить значит найти **все** функции, которые ему удовлетворяют (общее решение с константами), а потом по **начальному условию** $y(x_0) = y_0$ выбрать одну (задача Коши).

Почему инженеру это нужно: почти любой закон природы говорит, **как быстро** что-то меняется. Скорость изменения это производная, отсюда и ОДУ.

## Тип 1. Уравнения с разделяющимися переменными

$$y' = f(x)\,g(y).$$

Разносим: $\dfrac{dy}{g(y)} = f(x)\,dx$, интегрируем обе части.

### Пример: закон охлаждения Ньютона

Тело остывает со скоростью, пропорциональной разности температур: $\dfrac{dT}{dt} = -k(T - T_\text{ср})$.

$$\frac{dT}{T - T_\text{ср}} = -k\,dt \Rightarrow \ln|T - T_\text{ср}| = -kt + C \Rightarrow T(t) = T_\text{ср} + (T_0 - T_\text{ср})e^{-kt}.$$

Величина $\tau = 1/k$ называется **постоянной времени**: за $\tau$ разность температур падает в $e \approx 2.72$ раза, за $3\tau$ на 95%, за $5\tau$ на 99%.

### Пример: слив бака (закон Торричелли)

Скорость истечения $v = \sqrt{2gh}$, расход $Q = \mu a\sqrt{2gh}$. Баланс объёма для бака площадью $A$:

$$A\frac{dh}{dt} = -\mu a\sqrt{2gh} \Rightarrow \sqrt h = \sqrt{h_0} - \frac{\mu a}{2A}\sqrt{2g}\,t.$$

Время полного слива $t = \dfrac{A}{\mu a}\sqrt{\dfrac{2h_0}{g}}$.

## Тип 2. Линейные уравнения первого порядка

$$y' + p(x)\,y = q(x).$$

**Метод интегрирующего множителя**: домножаем на $\mu(x) = e^{\int p\,dx}$, левая часть превращается в $(\mu y)'$:

$$y = \frac{1}{\mu}\left(\int \mu\, q\,dx + C\right).$$

Альтернатива: метод Бернулли ($y = uv$) или вариация постоянной. Результат один и тот же.

### Пример: RC-цепь

Зарядка конденсатора от источника $E$: $RC\,\dfrac{du}{dt} + u = E$. Решение:

$$u(t) = E\left(1 - e^{-t/RC}\right),\quad \tau = RC.$$

Те же экспоненты, что и при остывании. Это не совпадение: все **системы первого порядка** (термопара, RC-фильтр, гидроаккумулятор с дросселем) ведут себя одинаково.

## Тип 3. Однородные и в полных дифференциалах (кратко)

- **Однородное**: $y' = f(y/x)$. Замена $y = ux$ сводит к разделяющимся.
- **В полных дифференциалах**: $P\,dx + Q\,dy = 0$, где $P_y = Q_x$. Тогда существует $F(x, y)$ с $dF = P\,dx + Q\,dy$, и решение $F(x, y) = C$.

## Алгоритм распознавания

1. Можно разнести $x$ и $y$ по разные стороны? Разделяющиеся.
2. $y$ и $y'$ входят линейно? Линейное.
3. Правая часть зависит только от $y/x$? Однородное.
4. $P_y = Q_x$? Полный дифференциал.
5. Ничего не подошло? Решай численно.

## Численно: метод Эйлера и Рунге–Кутта

**Эйлер**: $y_{n+1} = y_n + h\,f(x_n, y_n)$, двигаемся по касательной шагами $h$. Ошибка $\sim h$, грубо.

**Рунге–Кутта 4-го порядка** (стандарт де-факто): берёт четыре оценки наклона внутри шага, ошибка $\sim h^4$.

```python
import numpy as np
from scipy.integrate import solve_ivp

# Остывание детали после закалки: T0 = 850 °C, среда 20 °C, k = 0.05 1/с
k, Tenv = 0.05, 20
sol = solve_ivp(lambda t, T: -k * (T - Tenv), [0, 120], [850], t_eval=np.linspace(0, 120, 7))
for t, T in zip(sol.t, sol.y[0]):
    exact = Tenv + (850 - Tenv) * np.exp(-k * t)
    print(f"t = {t:5.0f} c   T = {T:6.1f} °C   точно {exact:6.1f}")
```

```calc
T0 = 850 | 100..1200 | °C | Начальная температура
Tc = 20 | 0..100 | °C | Температура среды
k = 0.05 | 0.005..0.3 | 1/с | Коэффициент теплоотдачи
tau = 1/k | | с | Постоянная времени
plot t: 0..5*tau | Tc + (T0 - Tc)*exp(-k*t) | T(t)
axes: t, с ; T, °C
```
